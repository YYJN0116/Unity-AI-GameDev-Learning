# 🎮 修仙世界记录簿 - 可运行测试第一版 (v0.1 Playable Standalone)

这是《修仙世界记录簿》的**第一个完整可运行网页测试版本**。无需外部 AI 依赖，离线即开即玩！

---

## 快速游玩方式

### 方式 1：双击直接打开
直接在文件管理器中双击打开本目录下的 **[`index.html`](file:///C:/Users/USER/Unity-AI-GameDev-Learning/Projects/Xiuxian-Game/可运行测试第一版/index.html)**，即可在浏览器中畅玩。

### 方式 2：使用 Node.js 本地服务器启动（推荐）
在终端中进入当前目录并运行：
```bash
node server.js
```
然后在浏览器中打开：
👉 **http://127.0.0.1:8000/**

## 本版特色与操作指南

1. **左侧角色面板（Taskbar）**：
   - 查看角色境界、升级进度条、气血、灵力气海、灵石与随身行囊。
   - **道友与人脉**：实时显示关键 NPC 的好感度、仇恨度与互动羁绊。
2. **中间历程与推演（Main Stage）**：
   - 包含正文事件回顾，以及绿色的**掷骰与判定卡片**（显示检定属性、耗时与数值增减）。
   - **8 大修仙行动**：修炼、探索、任务、商贸、结交、试炼/战斗、突破、休息。
   - 点击 **【⚡ 运转天道推演】** 即可直接由本地算法离线结算并推进时间。
3. **右侧滑出抽屉（⚙️ 系统与天道）**：
   - 点击右上角按钮随时展开。
   - 支持：一键生成新手散修【陆青云】、保存/加载本地存档、重置角色、公历时间调节、以及大模型提示词导出。
