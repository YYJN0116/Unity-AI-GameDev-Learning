# 📜 修仙世界记录簿 (Xiuxian Game)

欢迎来到《修仙世界记录簿》项目主页。本项目是一个基于原生 Web 构建的**轻量级、零运行时依赖、纯单机沉浸式文字修仙 RPG / 互动小说游戏**。

## ⚡ 极速启动游戏

1. **直接运行**：进入 [`可运行测试第一版/`](./可运行测试第一版/)，用任何现代浏览器双击打开 `index.html`。
2. **通过本地服务运行**：
   ```bash
   cd 可运行测试第一版
   node server.js
   ```
   在浏览器中访问：`http://127.0.0.1:8000/`

## 🌟 核心特色与当前状态

- **真正的单机自闭环**：无需配置 API Key，无需联网，内置离线推演引擎，随时随地秒玩。
- **类似《仙途》的紧凑沉浸 UI**：单页零全局滚动条，左侧掌控人物属性与人脉好感度，中间纵览事件纪事与掷骰卡片。
- **自编小说网状剧本（正在演进）**：未来将逐步接入作者自编的《青云坊市篇》主支线剧情网，带来媲美互动小说的代入感。
