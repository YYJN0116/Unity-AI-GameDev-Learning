## 1. 逐项答复《04 报告》§5 五大审查问题（T1–T5）

### 问题 1 (T1) · `state-template.json` 是否逐字段对齐 `v0.1-data-standard.md`？
> **答复：完全对齐！已彻底重写 `state-template.json`，所有字段严格依照既定标准落地。**
- **字段整改明细**：
  - 补齐丢失的 5 个字段：`character.id`、`character.age`、`character.identity`、`character.constitution`、`character.reputation`。
  - 彻底剔除 `character.vitality`，严格遵循 `v0.1-data-standard.md:94` 规定（不将伤势与生命值混用为一个字段，杜绝与 `injuries` 形成双轨记伤）。
  - `character.spiritualRoot` 修正为单字符串（移除错误的 `spiritRoots` 数组）。
  - `character.spiritualPower` 规范为 `{ value: null, unit: null, controlState: "" }`。
  - `character.fatigue` 规范为 `{ value: null, scaleId: null, description: "" }`（用 `description` 替换 `status`）。
  - `character.currencyBalances` 规范为 `[{ unit, amount }]`，彻底剔除冗余的 `currency` 显示名字段。
  - `character.relationships` 搭车升级为《05》§0.3 的多维离散关系模型。
- **关联修复**：`starters/placeholder-starter.json` 已同步对齐上述字段与 `startLocationId` 规范。

### 问题 2 (T2) · `tuning.json` 三处修正是否全部执行？
> **答复：全部执行完毕！**
- **T2-a 移除占位标记**：`currencies.lowGradeSpiritStone` 彻底移除了 `canon: false` 与 `placeholder: true`，确认为正史既成货币单位。
- **T2-b 补齐碎灵换算**：新增 `fragment`（碎灵），并配置固定账面汇率：`exchange: { to: "lowGradeSpiritStone", rate: 0.1, ledgerOnly: true }`（10 碎灵 = 1 下品灵石）。
- **T2-c 消除一词两义**：将 `tuning.json` 中的 `currencies.*.unit` 全部更名为 `displayUnit`（显示计量单位，如“枚”），与存档中 `currencyBalances[].unit`（货币标识符，如 `"lowGradeSpiritStone"`）彻底解耦，杜绝同名歧义。

### 问题 3 (T3) · 是否新增 `build-data.js --check` 并让 CI/npm 跑 `--check` 而非 `build`？
> **答复：全部执行完毕！**
- **确定性构建**：从产物中彻底移除了非确定性的 `buildTime` 时间戳，改为对所有源数据内容计算 SHA-256 哈希 `inputsHash`，确保相同数据产生字节级一致的文件，git diff 永不误脏。
- **防漂移检查**：
  - `scripts/build-data.js` 新增 `--check` 模式：在内存中重构并与磁盘现存的 `data-bundle.js` 做严格比对，一旦发现未编译漂移立即以 **`exit 1`** 报错中止。
  - `package.json` 新增 `"check:data": "node scripts/build-data.js --check"`，并在 `npm test` 中串联 `--check` 与 schema 校验。

### 问题 4 (T4) · 是否新增 `state-template.json` 校验与「必填字段反向检查」？
> **答复：全部执行完毕！**
- **校验器全面重构**：`scripts/validate-schema.js` 新增 `validateStateTemplate()`，内置 `CHARACTER_REQUIRED_FIELDS` 逆向必填反查清单，一旦漏填任何核心字段直接报 Error 并中止。
- **违规阻断**：严密检查并禁止出现 `character.vitality`、`character.spiritRoots` 数组或 `currencyBalances[].currency`。
- **子结构深检**：对 `tuning.json` 中的 `fatigue`、`cultivation`、`time`、`currencies` 及 8 大 `actions` 做逐项类型与正数边界检查。
- **外键完整性**：检查 `starters/*.json` 的 `startLocationId` 必须存在于 `world.locations`。
