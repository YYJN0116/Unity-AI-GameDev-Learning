# 世界与地点生成规则

本文规定每局游戏如何从既有设定中选择、组合并记录世界背景、区域和地点。它用于结构化生成，不把示例自动升级为固定正史，也不改变 `game-design.md` 中的修仙法则、资源原则、行动判定或开放式玩法。

## 1. 生成原则

- 世界由稳定的基础规则、可复用的设定库和本局专属状态组成。
- 生成结果一经玩家确认或在剧情中成为角色已知事实，就写入本局配置；后续保持一致，除非剧情因果或明确修订改变它。
- `game-design.md` 中的玄风宗、烈焰谷、月隐门、人间商会、玄海荒地、旧朝残迹，以及后山洞府、山门、坊市、冷泉谷、密林秘境、禁地前沿，均是设计示例/候选项。只有被选入本局并确认后，才作为本局设定。
- 未提供的地理、历史、势力关系和具体数值不得伪装成既有设定。新生成内容须标记为“本局生成”，并满足已确认规则。
- 世界不设置强制主线。地点和事件可以提供机会、风险或线索，玩家可以忽略；世界变化须有时间、行动者、信息和资源等因果依据。

## 2. 本局世界范围

开始生成前，从以下方式中确定一种：

1. **使用既有设定**：玩家指定或确认已存在的大陆、区域、地点和势力。
2. **组合设定库**：从已确认的大陆/区域/地点/势力条目中选择并组合。
3. **生成新设定**：玩家授权后，按本规则生成缺少的内容，并标记为本局新增；除非玩家另行决定，不自动写入永久设定库。

每局只生成当前玩法所需的范围。初始通常准备一个开局区域、一个主要落脚点、若干可达地点和相关势力；不要求一次生成完整大陆地图。数量由玩家偏好和场景需求决定，不用空白条目填满地图。

## 3. 生成流程

### 第一步：确认边界

记录玩家已指定的地点、题材倾向、探索范围、随机程度，以及希望保留或重新生成的设定。玩家明确指定的内容优先于随机结果；随机生成不得覆盖玩家已经确认的设定。

### 第二步：建立区域骨架

按需记录：

- 大陆或世界区域名称及状态（已确认 / 本局生成 / 传闻 / 未知）
- 开局区域的地貌、气候或灵气特点
- 与开局相关的交通方向、邻近区域和主要阻隔
- 当地日历、游戏日期和日内计时口径；若未确定，先列为待确认，不自行假定精确历法

只描述本局角色能够合理知道的内容。地图空白表示尚未设定或尚未知，不表示那里不存在内容。

### 第三步：选择或生成地点

地点可按需要承担不同功能，例如居住/修炼、交易/消息、交通/探索、宗门事务、危险区域或事件发生地。用途不是剧情锁定；同一地点可以有多个用途，玩家也可以提出未列出的行动。

每个已启用地点至少记录：

- 名称、类型、所属区域和状态
- 可观察到的环境特征与公开用途
- 已知的进入方式、相邻地点和旅行条件
- 可获得的服务、资源或信息（未知则标未知）
- 主要风险及其可察觉线索；不把角色不知道的秘密写入玩家可见描述
- 关联势力、NPC、事件（如有）
- 时间、物价或资源参数的来源与确定程度

如需设定距离、耗时、价格或风险等级，应在本局配置中明确数值、单位、适用条件和依据。没有可靠依据时标为“待校准/估计”，不得把估计说成角色已知的精确事实。

### 第四步：配置势力

根据本局范围选择相关宗门、世俗组织或其他势力。`game-design.md` 提出的 4–6 个重要势力是建议规模，不是每局必须全部出现的硬性要求。

每个启用势力记录：

- 名称、类型、活动范围及公开背景
- 核心价值观或目标
- 与玩家/开局地点的已知关系
- 财力、权力、资源和关键人物（只写已定义或本局确认的信息）
- 可观察的影响、限制和行动方式
- 隐藏动机或秘密的主持端记录位置（若本局启用）；不得混入玩家可见档案

势力关系必须能由利益、历史或行动解释。没有设定的关系维持未知，不自动推定为敌对或盟友。

### 第五步：检查一致性并确认

检查地点是否可达、交通和时间是否相容、势力是否有合理活动范围、资源供应是否有来源，以及开局场景是否给玩家留下自由行动空间。向玩家简要展示本局会影响选择的公开设定，并标出待确认项。只有玩家确认或授权自动生成后，才锁定本局配置。

## 5. 世界变化与版本记录

地点或势力发生变化时，记录变化前后状态、游戏内时间、行动者、原因、消耗/收益、受影响的地点/NPC/事件和玩家是否知情。测试场景和临时演练不得写入本局正史。跨局复用的条目只有在玩家明确同意后才并入公共设定库，并注明来源和版本。

## 6. 生成检查表

- [ ] 示例内容没有被误写为已确认正史。
- [ ] 玩家指定与随机生成的边界已记录。
- [ ] 本局地点、势力及其关系有来源或明确的生成标记。
- [ ] 时间、距离、价格和风险参数注明单位与确定程度。
- [ ] 角色可知信息与主持端隐藏信息分开保存。
- [ ] 没有强迫玩家追逐某条主线或进入特定地点。
- [ ] 地图空白、未知信息和未启用内容没有被擅自补全为事实。
