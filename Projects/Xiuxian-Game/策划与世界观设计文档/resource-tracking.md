# 资源追踪规范

本文规定 AI 主持时如何记录角色、NPC、地点和世界状态的变化，减少时间、物品和关系账目漂移。它规范记录方式，不增加新的属性、数值公式、换算率、阈值或战斗规则；具体游戏规则仍以已确认的项目文档和本局配置为准。

## 1. 追踪原则

- 所有有影响的变化都能追溯到行动、事件、时间经过或明确的规则效果。
- 记录行动前状态、变化量、原因和行动后状态。数值不明时标为未知/待校准，不虚构精确数值。
- 区分持有物、已消耗物、已承诺物、债务、名声、人情和关系；它们不可未经依据相互兑换。
- 玩家可见状态与主持端隐藏状态分开保存。玩家只收到角色已知或可观察到的信息。
- 资源结果服务于角色选择和世界因果，不为增加“游戏感”而给每个小动作额外扣费或判定。
- 若发现记录冲突，先暂停受影响的结算，核对最近确认的存档与日志，再说明并透明修正。

## 2. 需要追踪的状态

### 角色成长与身体状态

- 境界、修为进度、功法与掌握程度、技艺/能力变化
- 灵力状态、疲劳、伤势和其他已启用的状态
- 变化的来源、耗时、资源成本、风险与结果

只使用本局配置或规则文档已定义的量表。没有明确量表时，用文字描述状态并保持前后一致，不自行创造等级阈值。

### 物质与经济资源

- 灵石及其他已确认货币，按单位分别记账
- 丹药、材料、装备、法宝、功法、食物、工具等物品
- 交易数量、单价、总价、来源、去向及未结清部分
- 借款、债务、承诺、保管物和他人所有物

灵石、碎灵、铜钱或其他单位之间只有在本局规则明确时才换算。库存按实际数量和状态记录；耐久、品质、用途或归属有影响时一并记录。

### 社会与世界状态

- 与 NPC 的关系、信任/敌意/承诺及变化原因
- 名声、人情、宗门/势力身份、权限和任务状态
- 角色可知事实、传闻、线索、推断及其来源
- 地点状态、世界事件、已知期限与时间窗口

关系和名声若没有已确认数值尺度，可用有定义的文字状态记录，不强行转换为数字。

## 3. 每次行动结算流程

1. **确认行动**：复述玩家的有效意图；意图明确时不重复追问。
2. **核对行动前状态**：读取相关境界、资源、伤势、疲劳、物品、关系、地点和期限。
3. **确定时间与成本**：根据已确认的行动规则或本局校准值计算；未校准部分说明为估计或先询问玩家，不伪造精确性。
4. **处理结果**：简单且确定的行动直接成功；存在实质不确定性时，按已确认的能力、准备、信息、环境、风险和目标进行判断。说明重要依据及失败/成功的后果。
5. **记录所有变化**：资源增减、物品转移、状态变化、关系变化、时间推进和期间发生的世界/NPC行动分别记账。
6. **核对余额与因果**：重新计算余额、库存、时间和状态；确认每个变化都有原因，且未把推断写成确认事实。
7. **反馈并保存**：给出叙事结果、角色可观察信息、关键数值变化和当前状态；重大行动后更新存档和剧情日志。

若行动中断、部分成功或结果待定，记录已发生的成本和未完成部分，避免把预期收益提前入账。

## 4. 账本格式

### 行动流水

| 游戏内时间 | 行动/事件 | 资源或状态 | 变化前 | 变化量 | 变化后 | 原因/依据 | 确定程度 |
|---|---|---|---:|---:|---:|---|---|
|  |  |  |  |  |  |  | 确认 / 暂定 / 估计 |

每项变化单独一行，尤其是多种物品、多笔交易或同时影响多个角色的行动。若只改变关系或获得信息，也写明对象/内容、来源和知情范围。

### 交易流水

```text
游戏内时间：
交易双方：
物品/货币单位：
数量：
单价：
总价：
买方变化：
卖方变化：
未结清款项/债务：
价格来源与确定程度：
```

总价必须能由数量和单价复算。以物易物或赊账时分别记录各自交付、承诺与未结清部分。

### 状态快照

```text
游戏内时间与地点：
境界 / 修为进度：
功法与掌握情况：
灵力：
疲劳：
伤势：
货币余额（逐单位列出）：
物品库存（数量、状态、归属）：
关系与承诺：
任务 / 事件 / 期限：
角色已知事实：
传闻与线索（来源）：
角色推断：
待核实或待校准：
```

## 5. 时间与长期行动

修炼、闭关、疗伤、制作、调查、旅行、谈判等长行动需记录开始与结束时间、采用的计时口径，以及期间资源消耗、伤势/疲劳变化、期限推进、NPC 行动和世界事件变化。只有本局已定义的规则或明确叙事事实才产生这些变化；不可仅因经过时间就自动提升境界或完成未满足条件的目标。

旅程或行动耗时若是估算，应保留估算标记。多个行动不得在时间线上重叠，除非明确记录为并行行动，并说明参与者和各自耗时。

## 6. 信息与关系账本

信息须标记为确认事实、传闻、线索或角色推断，并记录来源、获得时间、可信程度和角色/NPC知情范围。主持端隐藏事实独立记录，不因玩家猜测自动改写，也不将未验证猜测升级为正史。

关系变化记录涉及双方的行动、原因、方向和时间；关系状态不得仅凭一次无关行动自动跃迁。NPC 有独立意愿和记忆，关系收益或损失须有符合其认知的依据。

## 7. 修正、回滚与结算错误

发现账目错误时：

1. 暂停依赖该数值的后续结算。
2. 对照最近一次确认的快照和逐项流水，指出冲突及受影响范围。
3. 依据可复核的行动记录重算，不用剧情解释掩盖记录错误。
4. 写明原记录、修正值、修正原因和是否影响玩家已知事实。
5. 更新当前快照及日志，并保留更正痕迹。

若无法确定正确数值，明确保留为待核实，并与玩家协商采用的处理方式；不得默默选择对剧情最方便的结果。

## 8. 每轮反馈格式

```text
当前局势与角色可观察到的信息：
行动结果与重要判定依据：
游戏内时间变化：
资源 / 状态变化（旧值 → 变化 → 新值）：
关系、事件或信息变化：
当前关键状态：
```

无变化的字段可以省略；不得为了填满模板而编造变化。玩家可自由提出下一步行动，选项只是提示，不是限制。

## 9. 核对清单

- [ ] 时间口径和行动耗时有依据，长行动已结算期间变化。
- [ ] 货币单位、数量、单价和总价可复算。
- [ ] 物品数量、归属、消耗与转移一致。
- [ ] 境界、修为、灵力、疲劳和伤势没有无依据变化。
- [ ] 关系、名声、人情、任务与事件变化有因果记录。
- [ ] 事实、传闻、线索、推断和隐藏状态正确区分。
- [ ] 玩家存档不含角色不可知的主持端秘密。
- [ ] 错误修正透明记录，未将测试场景写入正史。
