# 📚 修仙世界记录簿 - 策划与世界观设计文档

本目录归档了《修仙世界记录簿》早期的世界观设定、角色属性规划、NPC 模板及数据规约文件，供后续扩充剧情网和规则库时随时查阅。

---

## 目录文件清单

| 文件名 | 内容说明 |
| :--- | :--- |
| **`v0.1-data-standard.md`** | **底层数据标准规约**（境界阶梯、属性对象、状态补丁 statePatch 结构）。 |
| **`game-design.md`** | 游戏核心机制设计文档（六维属性、疲劳恢复、心境与道心）。 |
| **`character-creation.md`** | 角色创角规约（出身背景、灵根天资、初始词条）。 |
| **`npc-roster.md`** | 核心 NPC 名册与好感度/仇恨度矩阵。 |
| **`npc-generation.md`** | 随机散修/宗门修士生成协议与性格标签。 |
| **`resource-tracking.md`** | 经济体系与消耗平衡（灵石、丹药、草药、洞府租金）。 |
| **`world-database.json`** | 青冥洲初始地理与宗门世界数据库（JSON）。 |
| **`world-generation.md`** | 地理与势力生成规则。 |
| **`session-config-template.md`** | 游戏会话初始状态模板。 |
| **`ai-prompt-template.md`** | 外部大模型深度推演提示词模板。 |
| **`v0.1-milestone.md`** | v0.1 第一版开发里程碑记录。 |
