## 1. 项目概况与仓库信息

- **项目名称**：修仙世界记录簿（Xiuxian-Game）
- **核心定位**：基于原生 Web（HTML5 + CSS3 + 原生 JavaScript）打造的轻量级、无第三方运行时依赖、高沉浸感的**文字修仙 RPG / 互动小说游戏**。
- **开源代码仓库**：`https://github.com/YYJN0116/Unity-AI-GameDev-Learning.git`
- **项目子目录**：`Projects/Xiuxian-Game/`
- **分支规划**：
  - `main`：日常最新主干代码。
  - `v0.1-first-test`：**第一版完整测试专属归档分支**（供随时回滚、演示或比对）。
- **极速体验方法**：
  - 进入 `Projects/Xiuxian-Game/可运行测试第一版/`
  - 直接双击打开 `index.html`，或命令行运行 `node server.js` 并在浏览器访问 `http://127.0.0.1:8000/`。

## 2. 项目演进三阶段（从 ChatGPT / Copilot 到单机 Web）

### 阶段 1：ChatGPT / Copilot 孵化期（文档与规则制定）
- **成果**：在 `xiuxian_working_v1.5/` 中沉淀了 41 份极其严密、专业水准的世界观与 GM 规则体系，包括行动耗时、时辰与公历换算、灵力消耗、青冥洲势力图谱等。
- **局限**：原先只是一个纯粹的“提示词搬运网页”。玩家每做一个动作，都要把网页生成的 Markdown 复制到 ChatGPT 中，等 AI 生成 JSON 后再粘回网页。玩家体验像在做数据录入，无法独立成游。

### 阶段 2：工程化与 Playwright 自动化测试
- 引入了 Playwright 端到端自动化测试套件（`tests/xiuxian-flow.spec.js`），确立了以 `v0.1-data-standard.md` 为核心的数据补丁规范，对行动选择、挂起（pending）、成功结算（success）及本地恢复进行严格的 CI 质量保障。

### 阶段 3：单机自闭环与仙途式 UI 重构（当前节点）
- **内置离线天道推演算法**：编写了针对 8 大行动（修炼、探索、任务、商贸、结交、试炼、突破、休息）的本地推演逻辑，彻底告别必须联网粘大模型的依赖，实现单机自闭环秒玩。
- **全新单页视口架构**：参考《仙途》手游紧凑 UI，消除全局长滚动条，确立左侧角色状态人脉、中间历程纪事与行动、右侧系统抽屉的三栏沉浸布局。

## 3. 核心重大决策：解决“API Token 困境”与“自编小说路线”

> ⚠️ **请 DeepSeek 与 Gemini 重点研读本节：这是项目当前最重要的设计转向！**

### 3.1 现实痛点
若将游戏推向 GitHub Pages 或开源社区供大众游玩：
1. **若开发者提供 API Key**：玩家游玩会大量消耗开发者的 Token 钱包，存在被爬虫刷爆、限流和昂贵账单的高昂风险。
2. **若要求玩家自备 API Key**：国内绝大多数普通玩家根本没有境外大模型账号或绑定信用卡，这会劝退 95% 以上的用户。
3. **纯靠实时大模型叙事的不可控性**：大模型自由推演极易吃设定、前后矛盾、战力崩坏，且缺乏精心编排的主线伏笔与宿命感。

### 3.2 解决方案：开发者自编小说 + 网状事件体系（Gamebook 模式）
- **创作者亲自主导剧本**：开发者亲自撰写修仙小说的主线大纲、因果伏笔、关键事件与结局（类似《极乐迪斯科》、《太吾绘卷》的网状叙事）。
- **AI 角色重塑（转向开发后台）**：
  - **开发期（AI 当创作助手）**：开发者提供小说大纲，由 DeepSeek / Gemini 在后台协助细化成具体的支线选项、随机事件片段和数值判定逻辑，**不消耗玩家任何运行时 Token**。
  - **游玩期（玩家零门槛秒玩）**：游戏本体使用离线事件库和推演引擎，人人打开网页就能免费玩、零延迟、免登录。
  - **极客模式（保留兼容）**：右侧抽屉保留提示词导出功能，极客玩家仍可自选大模型进行长篇深度推演。

### 5.2 状态补丁协议 (`statePatch`)
所有的推演产出只针对需要修改的字段产生补丁，例如：
```json
{
  "character": {
    "cultivationProgress": 20,
    "spiritualPower": { "current": 8, "max": 10 }
  }
}
```
通过 `Object.assign` 安全合入，保障未改变字段不受破坏。

## 6. 前端视觉与交互布局规范 (仙途单页风格)

1. **单页零外部滚动**：整个游戏界面保持在 `100vh` 屏幕内，外部页面禁止滚动。
2. **左侧 Taskbar (330px)**：
   - 角色卡、境界进度条、精气神数值。
   - **道友与人脉专区**：动态呈现 NPC 名字、好感度、态度及互动备忘。
   - 随身行囊与灵石。
3. **中间主舞台**：
   - 顶部纪事流（历史叙事回顾）。
   - **核心亮点：掷骰与判定卡片**（清晰标明属性、判定评级 Badge、耗时与数值增减）。
   - `—— 何 去 何 从 ——` 分界装饰。
   - 8 大行动选项卡（修炼、探索、任务、商贸、结交、试炼、突破、休息）+ 行动输入框 + **【⚡ 运转天道推演】** 按钮。
4. **右侧滑出抽屉（⚙️ 系统与天道）**：
   - 点击右上角按钮随时展开。
   - 包含快捷开局、存档/读档/重置、日期调整、JSON 导入导出及高级 AI 调试。

## 7. 关键 Bug 修复与稳定性记录

- **选项卡不显示的排查修复**：
  在抽屉组件中使用 `<h3>` 导致 `panel.querySelector("h2")` 抛出 `TypeError` 并中断脚本，使得 `renderActions()` 未能执行。现已全面重构为多级安全选择器 `panel.querySelector("h2, h3")` 并添加 `prepend` 兜底，彻底消除此类隐患。
- **语言标头统一**：
  将 `index.html` 统一修正为 `<html lang="zh-CN">`，解决繁体字库异样及 Chrome 浏览器多余的弹窗提示。
