# 修仙世界记录簿 - v0.1 第一版测试归档说明

## 1. 版本概览 (v0.1 First Test Milestone)
本版本是《修仙世界记录簿》从原先的纯提示词交互（ChatGPT / Copilot 原型），演进为**单机离线可运行、沉浸式单页 Web 文字 RPG** 的第一个完整里程碑版本。

- **Git 分支**：`v0.1-first-test`
- **归档时间**：2026-10-15
- **核心特色**：无需依赖外部 AI 网络服务即可自闭环游玩，同时兼容外部大模型深度叙事模式。

---

## 2. 本版本核心功能清单

### 2.1 界面与交互体验
- **《仙途》风格三栏单页布局**：基于 `100vh` 纯视口设计，无全局垂直长滚动条。
- **左侧状态 Taskbar (330px)**：
  - 角色头像、名号、散修身份。
  - 境界等级与进度条（炼气期 1~9 层动态百分比）。
  - 精力、灵气气海、灵石行囊、灵根属性与当前所在地点。
  - **道友与人脉**：支持 NPC 羁绊、好感度、仇恨度实时监控展示。
- **中间核心历程舞台**：
  - 上方历程纪事（正文事件记录与多轮叙事）。
  - 核心亮点：**掷骰与判定卡片**（清晰标明检定属性、耗时、得失变动及成功/部分成功/失败评级 Badge）。
  - 分界标语：`—— 何 去 何 从 ——`。
  - 中间正下方：**8 大核心修仙行动选项**（修炼、探索、任务、商贸、结交、试炼、突破、休息）+ 自定义做法输入框。
- **右侧滑出式抽屉（⚙️ 天道神机与系统）**：
  - 快捷启程：一键生成标准新手散修角色【陆青云】。
  - 存档管理：本地进度保存、读取、重置、公历与当日分钟调整、JSON 导入导出。
  - 天道推演（原外部大模型工具）：生成规范的 AI 主持提示词，可复制至 ChatGPT/Claude 并粘贴返回 JSON。

### 2.2 离线单机天道推演引擎
- 内置针对 8 大行动类型的概率与确定性规则推演算法（耗时计算、灵力增减、疲劳度、灵石与丹药产出、突破概率判定）。
- 每次行动自动推进时钟并产生标准 Ledger 记录。
- 数据结构完全遵循 `v0.1-data-standard.md` 与状态补丁规范。

## 3. 运行与验证
直接在现代浏览器中打开 `index.html`，或通过 Node.js 启动静态服务：
```bash
node server.js
```
访问 `http://127.0.0.1:8000/` 即可体验。
