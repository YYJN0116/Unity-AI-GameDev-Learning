## 3. 与 `15_` 报告的三处出入（以 §7 为准）

1. **事件文件名示例不规范**：`15_` §3.1 写 `main.ch01.01.json` ✅ 可取，但 `side.ch01.xx.json`、`ambient.linchuan.xx.json` 不是合法 id 格式。文件名**必须等于事件 id**，`side` 的 id 是 `side.ch01.<两位序号>`，`ambient` 是 `ambient.<regionSlug>.<两位序号>`。
2. **`ambient` 示例把 `linchuan` 写死了**：临川镇目前仍是**暂定地名**（`17_GM` 文件自标）。slug 必须等 YY 定名后再冻结，现阶段**不得**把 `linchuan` 当既定 region slug 写进任何数据或测试。
3. **加载确定性与体积上限缺失**：`15_` 未规定"不得依赖文件系统返回顺序"与单文件 64 KB 上限。这两条是回归测试能不能稳定复现的前提，请补。
