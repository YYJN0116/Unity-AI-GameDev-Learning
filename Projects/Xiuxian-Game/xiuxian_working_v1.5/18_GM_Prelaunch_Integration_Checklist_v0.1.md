# 《修仙》正式开局前整合检查表 v0.1

> 这是交接与发布门槛，不代表所有项目已完成。每一项需标记“通过 / 未通过 / 不适用”，并记录对应文件与理由。

## A. 核心规则一致性
- [ ] 境界顺序在玩家手册、主持端规则与存档模板完全一致。
- [ ] 感气与炼气的关系、炼气九层与筑基门槛写法一致。
- [ ] 功法品阶与掌握阶段不混为一谈。
- [ ] 灵根、体质、悟性、经验、资源各自独立，不出现重复加成。
- [ ] 飞行、神识、跨境界战斗的能力边界没有互相矛盾。
- [ ] 伤势类型、治疗限制、突破风险在判定协议与存档字段中可记录。

## B. 数值与经济
- [ ] 开局地区的物价基准已确认，不同文件引用同一版本。
- [ ] 铜钱、碎灵、低阶灵石的关系已在开局地区明确说明。
- [ ] 路程与地图尺度互相匹配，步行/商队/雨天的差异可解释。
- [ ] 修炼、疗伤、制作、调查与赶路的耗时能放进同一时间账本。
- [ ] 所有已发生交易均能重算；收入、支出、库存与欠账平衡。
- [ ] 不使用没有来源的精确修炼时间、物价、成功率或伤势恢复时间。

## C. 信息与隐藏真相
- [ ] 玩家手册没有泄露主持端隐藏历史、人物真实动机或未发现的结局条件。
- [ ] 玩家可见存档不包含主持端隐藏附页。
- [ ] 每个关键结论至少有两种合理的调查路径，或明确注明为什么只有一条路径。
- [ ] 传闻、推断、已确认事实标注清楚，并记录来源。
- [ ] NPC只依据自身经历、来源和推理行动，不会无缘无故全知。
- [ ] 主持端犯错时按纠错流程透明修复，不包装成剧情。

## D. 事件与NPC
- [ ] 每个活跃事件都有触发条件、参与者目标、可见线索、可介入点与不介入结果。
- [ ] 事件不因玩家忽略而自动升级为灾难；升级必须满足条件。
- [ ] NPC有自身目标与行动窗口，但行动需要时间、资源、信息与机会。
- [ ] 关系将信任、好感、利益、恐惧、义务等分别记录。
- [ ] 同一人物在不同场景的行为与已知信息一致；若变化，记录原因。
- [ ] 玩家选择能改变结果，不保证每条路径都通往同一预设结局。

## E. 开局准备与新聊天交接
- [ ] 已确定正式采用的开局地点；若采用临川镇，名称与三类组织需统一登记。
- [ ] 已确认游戏内日历、时辰习惯与初始日期。
- [ ] 玩家确认或授权随机生成角色身份、境界、灵根、体质与初始物资。
- [ ] 开局第一幕有具体时间、地点、可观察细节和可采取行动，不用百科式长篇讲设定。
- [ ] 已生成空白玩家存档与独立主持端隐藏状态档。
- [ ] 已生成《新聊天启动包》：公开规则摘要、当前正式版本、文件清单、存档格式、主持端执行原则；不得把隐藏真相写进玩家启动文本。
- [ ] 明确当前仍是草稿的部分，不把未校准数字当成既定世界事实。

## G. 版本纪律

1. 规则变更写明版本、原因、影响范围和生效时点。
2. 已经在游戏中发生的事实不可无理由回溯改写。
3. 主持端隐藏真相与玩家已知信息分开保存。
4. 正式开局前允许集中校准；开局后以兼容性修正为主，不随意推翻规则。
