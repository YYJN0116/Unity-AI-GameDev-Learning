# 《修仙》玩家偏好与非剧情设置确认表 v0.1

> 本文件用于正式开局前校准体验，不涉及幕后真相、阵营秘密或剧情答案。原则：能用安全默认值处理的，不把问题全部丢给玩家；只确认会显著影响体验的偏好。

## 1. 不应混淆的两类选择

### A. 必须由玩家决定或明确授权

- 角色是自建，还是授权主持端随机生成。
- 开局地点：采用候选地区、另选地区，或授权主持端选择。
- 是否接受随机角色摘要直接开局，还是先确认角色卡。
- 角色明确的边界：不希望出现的内容、不能接受的玩法或需要淡化的主题。

### B. 可以使用默认值，玩家随时可调整

- 叙事详略、战斗记录密度、是否显示精确账目、随机性强弱、失败描述尺度、NPC名字风格、存档更新频率。
- 默认采用：中文叙事；场景有画面但优先保留可行动信息；重要交易/伤势/战斗/突破精确记账；普通生活简化；高风险行动提前说明角色能察觉的风险；不为无意义动作频繁掷骰；每个重要场景结束后更新简明存档。

## 2. 建议采用的默认体验

| 项目 | 默认 | 调整原则 |
|---|---|---|
| 叙事风格 | 有画面感、行动优先，不写成长篇百科 | 玩家要求时可更文学化或更简洁 |
| 行动自由 | 开放式；建议选项不构成限制 | 玩家可随时提出其他方案 |
| 数值显示 | 关键数值显示，后台复杂推演不全量倾倒 | 交易、伤势、修炼和战斗结果可复核 |
| 随机性 | 因果判定优先；不确定性确有意义时才使用随机 | 若要骰子化，需先统一机制 |
| 战斗细节 | 说明位置、风险、结果与可选应对，不默认逐帧模拟 | 可按战斗重要性调整细度 |
| 失败尺度 | 后果与风险相称；死亡可能存在但不靠突袭式惩罚 | 角色可察觉的重大风险须先提示 |
| 资源管理 | 关键资源精确记录，普通消耗按场景合理简化 | 任何简化都不得改变已确认余额 |
| 存档频率 | 重要场景结束、重大状态变化、长时间跳跃后更新 | 玩家要求时可增加频率 |
| 内容边界 | 未确认前不主动加入露骨性内容或针对玩家的羞辱 | 具体禁区可另行说明 |
| 角色死亡 | 视为重大且通常不可逆后果；不默认复活 | 若想使用低惩罚模式，应开局前说明 |

## 3. 开局前最少确认事项

如果玩家说“按默认直接开始”，不再逐项盘问，使用以下默认：

1. 地点：由主持端从已完成的候选地区中选择一个普通、可生存、非强制主线的开局点。
2. 角色：随机生成普通但有行动空间的角色；不默认天选之人、孤儿、血仇或特殊血脉。
3. 境界：感气或炼气初期，优先让初始能力容易理解、规则容易验证。
4. 风格：自由行动、世界自主推进、因果优先、隐藏信息不剧透。
5. 存档：玩家可见状态和主持端隐藏状态分开；公开存档只写角色能够知道的内容。

若玩家未授权随机生成，不得以“默认值”为由擅自决定角色身份与重大人生经历。

## 4. 讨论边界：哪些可以与剧情无关地先讨论

玩家可以在任何时候讨论并改变以下设置，不会被当作角色行为，也不应改变世界内事实：

- 玩法复杂度：轻量叙事、标准规则、偏硬核记账。
- 随机机制：纯因果判定、隐藏随机、公开骰点；未选择前使用因果判定优先。
- 战斗风格：叙事式、战术式、混合式。
- 角色失败与死亡：标准风险、降低致死性、硬核永久后果。
- 叙事长度与节奏：短回合、标准、偏小说化。
- 资源管理：精确记账或普通消耗简化；重要交易始终精确。
- 是否允许角色重开、平行存档或非正史测试；默认测试角色不算正式正史。
- 内容边界、避雷主题、关系/恋爱内容的呈现程度。
- 是否在每轮末尾提供可选行动建议；默认提供少量建议，同时明确自由行动始终有效。

## 5. 不应过早要求玩家决定的事项

- 世界隐藏真相、幕后人物真实动机、阵营秘密、结局条件：由主持端负责设计与维护，不要求玩家替主持端编写。
- 每个地区的完整物价、每件物品配方、所有 NPC 名单：只在实际需要时逐步建立。
- 角色未来必须加入哪个势力、走哪条修炼路线、是否承担世界级目标：不提前锁定。
- 精确到秒的战斗规则或全世界统一的修炼天数：没有必要时不强加。

## 6. 偏好变更规则

- 体验偏好可以随时修改；若影响已经发生的游戏内事实，优先从下一场景生效，不回溯抹掉结果。
- 内容边界可以立即调整；若某类内容令人不适，直接淡化、跳过或改写，不要求玩家解释原因。
- 规则模式的改变要记录版本与生效时间，避免同一场战斗中途换规则。
- 角色设定与玩法偏好分开保存，避免把玩家现实偏好误当作角色性格。

## 7. 用户已确认的默认体验设置（2026-10-10）

以下不是待选择建议，而是用户明确确认、后续默认采用的项目设置。它们属于玩法呈现层，不属于角色设定，不改变任何隐藏剧情真相、历史事实、NPC真实动机或结局因果条件。

| 项目 | 已确认默认 | 执行口径 |
|---|---|---|
| 硬核程度 | **标准** | 重要资源、交易、伤势、战斗与突破精确记录；普通生活与重复操作适度简化。 |
| 战斗风格 | **混合式** | 重要战斗处理位置、距离、资源、伤势、策略与撤退；普通冲突按影响简化，不做无必要的逐帧模拟。 |
| 随机性 | **因果优先** | 先依据能力、准备、环境、信息和对手目标判定；只有确有意义的不确定性才考虑随机，不凭空掷骰。 |
| 死亡与失败尺度 | **标准风险** | 死亡真实存在且通常不可逆；重大风险应提前提示角色能够察觉的部分，失败后果与已知风险、行动方式和因果相称。 |
| 叙事节奏 | **均衡** | 兼顾环境氛围、人物反应和可行动信息；避免过度简略，也避免长篇描写挤压玩家行动空间。 |

### 优先级与变更规则

1. 以上设置是默认值，不是不可更改的硬性限制；用户可随时明确调整。
2. 未收到新指示时，所有后续文件、模拟测试、新聊天启动文本与正式主持均应采用这组设置，不得继续把它们写成“待用户选择”。
3. 临时测试角色仍不是正式角色；确认这些偏好不等于授权主持端创建正式角色或启动剧情。
4. 偏好变化只改变玩法执行与呈现方式，不得用于改写隐藏历史、NPC真实动机、已发生的世界事件或为了迎合玩家而改变线索真伪。
5. 若偏好变更会影响一场正在进行的战斗或行动，应尽可能从下一场景或下一次明确确认的节点生效；内容安全边界可立即生效。

## 8. 仍需玩家决定或明确授权的事项

- 正式角色身份、背景与是否接受随机生成。
- 正式开局地点，或是否授权主持端从候选地点中选择。
- 角色可接受的特殊内容边界，以及是否需要淡化某些主题。
- 是否把角色摘要确认后再开局，还是明确授权随机生成后直接开始。

这些事项不能仅凭上述默认玩法偏好推定。隐藏历史、人物秘密、阵营计划和结局设计仍由主持端负责，不要求玩家代写。


## 9. 用户补充确认：成长速度、资源压力与迷茫（2026-10-10）

用户确认以下为成长体验目标，而非剧情要求：
- 普通角色可以长期成长，不要求必须依靠天赋异禀、顶级宗门或稀有机缘；但成长速度可以比较慢。
- 经济与修炼资源会造成阶段性卡关；玩家可能感到迷茫，这种压力可以存在，不应被自动抹平。
- 卡关不能因为主持端遗漏可行选项而变成无解软锁。主持端应保留真实代价与玩家选择，同时在玩家迷茫时提供不剧透、不强迫的分层方向提示。
- 这三项只约束成长节奏与主持方式，不构成任何主线、角色背景或隐藏剧情的设定，也不得改变隐藏真相。
- 执行细则见 `34_GM_LongTerm_Progression_and_Softlock_Guardrails_v0.1.md`。
