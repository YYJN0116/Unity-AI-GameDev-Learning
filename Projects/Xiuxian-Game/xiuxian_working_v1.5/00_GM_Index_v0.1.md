# 《修仙》主持端总索引 v0.1

> 机密级别：主持端专用。不得直接展示给玩家角色。
> 状态：第一版工作档案；已建立核心因果骨架，后续扩展须遵循变更流程。

## 1. 项目原则
- 开放式主线：玩家选择真实改变人物命运、势力关系、事件结果与可达路线。
- 世界自主运作：NPC、势力与事件依据自身目标和条件行动，不等待主角。
- 底层真相稳定：隐藏答案先于揭露而存在，不因玩家猜测临时改写。
- 故事独立为主、自然交汇；并非所有事件都与世界级秘密有关。
- 伏笔可显性、隐性或长期潜伏，但角色合理可察觉的信息不可被主持端故意藏掉。
- 角色视角优先；必须区分世界事实、人物信念、传闻与玩家角色已知信息。

## 2. 文件模块
- `01_GM_True_History.md`：真实历史、两次历史转折、飞升与世界本源（机密）。
- `02_GM_Factions_NPC_Framework.md`：势力运行、人物建档标准与认知边界（机密）。
- `03_GM_Events_Clues_Endings.md`：事件状态机、线索公平性、分支与结局逻辑（机密）。
- `04_Player_Handbook_DRAFT.md`：玩家可见规则草稿；不得包含幕后真相。
- `05_Live_Save_Template.md`：开局后使用的角色与世界状态模板。
- `06_Chronicle_Change_Log.md`：事件回顾、变更记录与连续性修正。

## 3. 核心真相的稳定锚点（摘要，不写出答案）
- 两次重大历史转折不是简单重复，但存在可验证的因果联系。
- 飞升记录并非全真或全假；不同文明、时代与修为层级掌握的证据不同。
- 深层灵气异常存在自然规律和历史成因；不是所有异常都属于同一现象。
- 现代势力对古史的认知存在差异，差异来源包括证据缺失、立场偏见、误读与有意隐瞒，不能统一归因于单一阴谋。
- 世界级秘密至少存在多条发现路径；任何单条路径都可被错过，错过不令世界停止。
- 结局是世界状态、人物行动、玩家选择与可达条件的结果，不预设唯一救世或飞升结局。

## 4. 设定记录格式
每个重要条目记录：ID、状态（确定/暂定/传闻/已废弃）、真实内容、玩家可见版本、知情者、证据来源、前置条件、因果影响、关联条目、最后核对版本。

## 5. 变更流程
1. 说明变更原因与证据。
2. 检查相关人物、事件、线索、历史记录与当前存档。
3. 更新本体档案与索引引用。
4. 写入变更日志，说明是否影响已发生事件。
5. 不得把主持端错误伪装成世界秘密；若修正影响玩家已知信息，应透明处理。

## 6. 当前进度
- 已建立：基础修仙规则、世界运行规则、开放式主线原则、档案结构。
- 本轮工作：建立隐藏历史与当代世界的因果骨架，开始形成可执行的幕后设定。
- 未完成：完整幕后史、人物与势力档案、线索网、结局逻辑、四份正式游戏文件的最终校验。
