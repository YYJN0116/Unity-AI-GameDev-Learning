# 《修仙》临时角色首日完整演练 v0.1

> 主持端测试文件。临时角色与测试地点不自动成为正式世界事实。目标是检查角色创建、第一幕、行动结算、时间、资源、NPC反应与存档能否闭环。

## 1. 测试范围与限制

本轮采用临川镇作为测试场景，仅因已有地区草案；不等于正式开局已选临川镇。游戏日暂以“初秋某日”记录，不指定正式纪年。所有价格为普通地区基准示例，不当作正式地方行情。测试角色不是玩家角色。

本轮不掷骰，不设隐藏强制剧情；遇到没有具体条目的能力，不临时编造精确成功率。

## 2. 临时角色卡

- 姓名：沈砚（测试用）
- 年龄：二十岁上下
- 出身：小镇外的普通农户家庭，曾替药铺做过短工
- 境界：炼气一层
- 灵根：五行灵根，具体强弱未知；不得仅凭此标签断言修炼效率
- 体质：无已知特殊体质
- 功法：基础引气诀（入门）
- 术法：照明诀（初识）；无已知战斗术法
- 状态：无伤，灵力正常，轻度疲劳
- 现金：50碎灵；另有少量凡俗铜钱，但两种货币不自动兑换
- 物品：旧衣、布水囊、干粮一份、药铺短工留下的普通收据一张
- 近期目标：找到一份能维持基本开销的短工
- 长期困扰：想查明一位旧识为何突然离开小镇，但目前没有足够线索
- 关系：药铺伙计认识角色，关系中性偏熟；没有承诺会提供工作或借钱

### 初始预算核对

50碎灵为可用现金。普通地区基础生活开销按每日5–20碎灵估算，实际消费仍按具体报价结算。角色没有储物袋、丹药或战斗法器，不把背景经历自动转成额外技能。

## 3. 第一幕测试场景

**时间**：初秋，辰时前后（测试时段；正式日历待定）

**地点**：临川镇外街，靠近药铺与早市的路口。

角色能直接观察到：
1. 早市刚开始收拾摊位，几名脚夫正在争论一车药材的装卸次序。
2. 药铺门口贴着一张招短工的纸，但字迹被雨水洇开，工钱部分看不清。
3. 街对面有一名穿灰衣的旅人向人打听镇外渡口，旁人只说今日水位偏高；这只是当地人的说法，不等于渡口已关闭。

当前限制：角色只有50碎灵，不能把不确定的招工信息当成已到手收入；没有证据表明旧识与药材争执、灰衣旅人或渡口有关。

可行动方向包括查看招工告示、进药铺询问、向脚夫打听早市情况、询问渡口路况、练习照明诀或自由提出其他行动。以上不构成强制任务列表。

## 4. 连续行动模拟

### 行动 A：查看招工告示

- 耗时：1刻左右。
- 结果：角色能看出药铺需要一名临时搬运/整理帮手，但工钱字迹模糊，具体时长与报酬尚未确认。
- 信息层级：告示存在为已确认事实；工钱与工作时长为未知。
- 下一步：询问药铺伙计，或比较其他工作。
- 账目：无收入、无支出。

### 行动 B：向药铺伙计询问

- 耗时：2刻左右。
- 结果：伙计说明掌柜可能需要半日帮手，先搬货、后清点；需由掌柜确认工钱。伙计不承诺录用，也不替掌柜作主。
- NPC逻辑：伙计知道缺人，但不知道掌柜最终是否录用；他没有理由无条件替角色担保。
- 账目：无收入、无支出。
- 时间累计：3刻。

### 行动 C：角色选择先问清工钱，再决定是否接活

- 耗时：额外2刻。
- 结果：掌柜报出半日工钱12碎灵，结工时支付；若货物清点出现差错，角色只对自己实际负责的部分解释，不默认承担整批药材损失。
- 判定：这是明确报价，角色可以接受、议价、询问工作风险或拒绝。不得先让角色工作完才临时改价。
- 账目：尚未接受，收入仍为0。

### 行动 D：接受半日工作

- 耗时：约半日，具体结束时段由工作进度与休息确定。
- 结果：角色完成普通搬运和整理。没有特殊事故，不额外制造冲突。掌柜按先前报价支付12碎灵。
- 收入账目：+12碎灵。
- 现金余额：50 + 12 = 62碎灵。
- 技能变化：角色可能更熟悉药材搬运流程，但没有足够证据把“药材鉴别”提升为入门或熟练；劳动经验与专业技能分开记录。
- 世界推进：早市在这段时间继续交易。除非有证据，不把脚夫争执升级成阴谋或主线事件。

### 行动 E：工作结束后购买晚间补给并办理住宿

- 报价：简易修士补给1份，3碎灵；普通客房一夜，5碎灵（均为基准示例，正式地区价格仍需确认）。
- 支出：3 + 5 = 8碎灵；余额：62 - 8 = 54碎灵。
- 库存变化：购买后新增“简易修士补给×1份”。本次测试假定角色当晚实际食用该份补给，因此再记录“简易修士补给 -1份”；原有“干粮×1份”未食用，仍保留。若角色没有吃，则补给应留在库存，不能同时扣除。
- 住宿为一夜服务，不进入物品栏。购买与办理住宿合计暂记1刻，属于测试用时间估算。

### 测试时间线（非正史）

- 辰时前后开始：查看告示1刻，询问伙计2刻，向掌柜确认条件2刻，共5刻。
- 接受半日工作：暂按4时辰（16刻）计，含工作中的必要短暂停顿；工作结束后结算工钱。
- 购买补给与办理住宿：1刻。
- 本日已记录行动合计：22刻，即5时辰30分钟；若开场为辰时初，结束约在未时中段。由于“半日工作”原文与实际累计时间的口径此前不够明确，本轮统一按4时辰处理；正式游戏应按场景起止时点精确记账。

## 5. 首日结束状态快照

- 现金：54碎灵；本日收入12碎灵，支出8碎灵，净增加4碎灵。
- 境界：炼气一层，未突破。
- 功法：基础引气诀（入门）；没有因劳动自动升级。
- 术法：照明诀（初识）；本日未练习，不升级。
- 伤势：无。
- 疲劳：轻度，经过晚间休息后预计改善；具体恢复按睡眠与先前负荷判断，不强行写成完全恢复。
- 物品：旧衣×1、水囊×1、干粮×1份、普通收据×1；简易修士补给购买×1并食用×1，期末剩余0份。住宿一夜是服务，不是物品。
- 关系：药铺伙计仍为中性偏熟；掌柜见过角色并支付工钱，尚不足以建立高信任。
- 已确认信息：药铺曾招半日帮手；掌柜支付12碎灵；住宿和补给本次实付8碎灵。
- 未确认信息：旧识离镇原因；灰衣旅人的身份与目的；渡口是否关闭。
- 活跃事件：旧识线索仅是角色个人目标，不自动成为紧迫事件；无已知期限。

## 6. 本次暴露出的缺口

1. **正式日期未定**：正式开局前需由玩家接受一个日历方案，或授权主持端采用简洁的季节/月份/日格式；不用先建立复杂历法。
2. **临川镇未被正式采用**：它只能作为候选测试区，正式开局必须确认地点，或由玩家另选。
3. **补给消耗粒度**：本轮明确示例为购买简易修士补给×1并当晚食用×1，原有干粮×1保留；若行动改变，库存也必须随之改变。
4. **工作报酬与时间**：凡有雇佣行动，必须先说明工作内容、预计时长、报酬、风险与付款时点。
5. **旧识线索未形成事件**：只有角色个人疑问，没有可核实线索时，不应凭空生成“失踪案”或逼迫角色追查。
6. **NPC初始信息记录**：药铺伙计只知道招工与掌柜意向；掌柜知道工资和工作安排；两者知识不能合并为全知信息。
