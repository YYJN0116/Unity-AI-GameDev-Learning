# 《修仙》行动与经济校准补充 v0.1

> 主持端执行补充：让现有数值基线可在场景中直接使用，不引入每次行动都掷骰的繁重系统。

## 1. 时间单位统一
- 默认 1刻 = 15分钟；4刻 = 1时辰；1日按12时辰记账。地方可以使用不同称呼，但主持端换算统一。
- 游戏账本记录到刻；只有战斗才细分动作段。同一段时间不得重复计入调查、赶路或制作。
- “半日”“数日”等模糊耗时，在行动前转换为合理区间；期限紧迫时先告知角色能察觉的时间压力。

## 2. 货币与经济
- 1枚低阶灵石 = 10枚碎灵，仅作账面换算；铜钱与灵石没有固定兑换率。
- 低阶修士一日基本开销 5–20碎灵；有稳定灵气或阵法辅助的修炼室每时辰 1–4枚低阶灵石。二者是不同消费层级，不能混淆。
- 未知价格允许先询价。不得在角色完成行动后才追加此前无法察觉的费用。
- 赊账必须双方同意，记录额度、期限、利息或人情代价、违约后果；默认不自动借债。
- 议价要有依据，例如行情、数量、关系、信用或有价值的交换条件。以物易物取决于双方需求，不存在唯一绝对价格。

## 3. 行动难度四档
| 档位 | 适用条件 | 处理方式 |
|---|---|---|
| 顺手 | 会做、条件齐、无有效阻碍 | 直接成功，花正常时间 |
| 有挑战 | 有明显困难，但能力或准备可应对 | 按优势与代价结算 |
| 高风险 | 失败会造成显著损失，或多项条件不利 | 先提示可察觉风险，再让玩家决定 |
| 当前不可行 | 缺少硬性能力、关键工具或必要条件 | 说明缺口，允许换方法或准备后再试 |

若玩家的方法真实改变了条件，重新评估难度；不能只因玩家目标大胆就自动判失败。

## 4. 成长的可复核门槛
- 入门：能在熟悉条件下完成基本步骤，但仍需专注或提醒。
- 熟练：多次稳定完成常见操作，能识别典型错误。
- 精通：能应对变化条件、调整方法并解释关键原理。
- 自成体系：形成可重复验证的改良方法，或能说明适用边界并教会他人。
技能阶段必须有训练、反馈、失败或实际应用作为证据。单次惊险成功可以带来理解，但不自动等于掌握。

## 5. 突破记录单
每次突破准备记录：目标境界/层次、积累是否充分及依据、功法适配与缺陷、身体/灵力/神魂状态、环境与资源、可察觉警讯、失败后果范围、成功后的巩固要求、实际耗时与消耗。
低风险不等于零风险；高风险不等于必败。结果必须由具体条件解释。

## 6. 交易例
常见药材报价 4碎灵/份，购买3份标价12碎灵。若有合理批量议价条件，谈至3碎灵/份，则实付9碎灵。账本记明日期、地点、物品、数量、单价、总价、付款来源、卖方、议价依据与余额变化。余额不足时可以减量、换物、谈分期或放弃，不自动借债。

## 7. 未量化能力
这份文件统一裁定口径，不代表每种术法、丹药和法器已有完整数值。能力首次重要登场时建立条目，记录范围、成本、限制、可见迹象与反制方式；之后重复使用同一条目，不临时改值。
