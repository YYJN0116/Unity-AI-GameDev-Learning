# 《修仙》主持端势力与人物框架 v0.1

> 主持端内部文件。具体名称、人物与关系按游戏需要生成，避免预制庞大但静止的名册。

## 1. 势力构建原则
每个重要势力必须有：
- 公开目标与实际利益（两者可以重叠，也可以冲突）。
- 资源来源、资源短缺与权力基础。
- 内部派系、代际差异、制度约束与继承问题。
- 已知信息、错误信念、未知事项及其来源。
- 对外关系与合作/冲突的具体原因。
- 采取行动的能力、成本、时间窗口与风险。
- 玩家介入后可变化的状态，不预设固定结局。

## 2. 势力类型与典型利益（不是善恶阵营）
- 顶级宗门：维护传承与区域秩序，同时争夺人才、资源和解释历史的权威。
- 地方宗门：重视生存、弟子、领地与与上级势力的关系；可能务实，也可能抱有扩张野心。
- 修仙家族：看重血脉、产业、婚盟、声誉和长期安全，内部继承冲突不可避免但不必每家都有。
- 商会与交易网络：重视稳定路线、信息差、信用和利润；会避开无利可图的危险，也可能资助高风险探索。
- 散修组织：通过互助、委托、情报或共同利益形成关系，组织约束通常弱于宗门。
- 独立强者：行动自由但也受资源、声誉、旧债、仇敌和修炼需求限制；强大不代表无成本。
- 凡俗政权：掌握人口、粮食、道路、税赋与军政秩序；与修仙势力互动时拥有真实筹码，但不同地区差异很大。

## 3. NPC档案模板
- ID / 姓名 / 当前身份 / 大致年龄与境界
- 外在表现 / 私人目标 / 长期目标 / 眼前压力
- 能力与限制 / 资源与债务 / 当前地点 / 时间安排
- 真实掌握的信息 / 错误信念 / 不知道的关键事项
- 对玩家的态度 / 信任程度 / 已记录互动 / 关系变化原因
- 已知秘密 / 保守秘密的动机 / 愿意透露的条件
- 可能采取的行动 / 行动前置条件 / 失败或受阻后的替代方案
- 可发现线索 / 玩家可能误解的表象 / 与其他档案的关联

## 4. NPC认知边界
- 只记得亲历或有合理渠道获知的事情。
- 传闻传播需要时间、渠道与可信度；不能瞬间全世界同步知晓。
- NPC可撒谎、误判或自欺，但必须符合其动机、知识和风险判断。
- 态度、信任、利益一致与忠诚是不同变量。
- NPC可以主动行动，但不得替玩家决定玩家角色的行动或内心。

## 5. 势力状态更新
重大事件后检查：领导层、资源、声誉、盟友、敌对关系、内部矛盾、公开叙事、秘密情报与可执行能力。变化幅度须与事件规模、证据传播和时间相称。
