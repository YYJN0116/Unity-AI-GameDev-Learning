# 《修仙》角色创建与开局协议 v0.1

> 主持端执行文件。随机生成须尊重玩家授权，不等于主持端可以替玩家决定所有人生。

## 1. 创建顺序
先确认两件事：是否采用候选开局地区临川镇；玩家自建角色还是授权随机生成。玩家已明确授权随机后，不重复询问同一问题。

角色摘要最少包含：姓名/称呼、年龄段、出身与成长环境、当前境界、修炼路线、灵根与体质（若已知）、功法/技能与掌握阶段、身体状态、关键物品、货币、一个近期目标、一个长期愿望或困扰、一段重要关系（或说明暂时没有）。

## 2. 随机生成原则
- 先给完整角色摘要让玩家确认，再写入正式存档；若玩家明确要求“随机并直接开始”，可简短确认后开局。
- 不默认生成孤儿、穷人、宗门弃徒、穿越者、天选之人、血仇或特殊血脉。普通出身与普通能力同样有效。
- 灵根、体质、悟性、性格和经验分别记录，不合并成一个万能天赋。
- 特殊天赋必须有可说明的效果、限制与已知范围，不得暗中追加无限能力。

## 3. 开局强度
- 未指定境界时，可建议从感气或炼气初期开始，但须让玩家确认，而非当作唯一正确玩法。
- 较高境界须配套合理履历、资源、技能和社会关系，不能只提高境界数字。
- 初始资源要支持已确认的背景和近期目标，但不免费附送与背景不相称的高阶法宝、巨额灵石或完整高阶传承。
- 功法可常见、有限或不完整；后续获取必须有公平、可追踪的途径。

## 4. 世界连接点
角色至少有一个可行动的连接点：工作、熟人、债务、承诺、学习目标、旅行目的、家族事务、组织登记或主动调查。连接点不是强制主线，玩家可拒绝。
记录涉及人物、地点、时间/资源需求、目前已知内容及对方可能拒绝的事项。

## 5. 第一幕必须包含
- 明确游戏内日期/时段和地点；
- 至少三个可感知的具体细节；
- 当前能做的事与现实限制；
- 至少两个性质不同的行动方向，但不把玩家限制在选项里；
- 不强迫接受任务，不倾倒完整世界历史；
- 玩家视角看不到的秘密不出现在叙事中。

## 6. 正式开局完成条件
玩家确认角色摘要；初始物资账目可重算；地点、日历与货币基线已定；玩家可见存档已建立；主持端隐藏状态独立保存。完成后才标记正式开局。
