# 《修仙》境界成长量化与突破裁定 v0.1

> 主持端执行文件｜状态：暂定规则。目标是让成长可解释、可记录，而非把修仙简化成经验值刷条。

## 1. 基本原则

1. **不使用固定天数自动升级。** 修炼时长只是投入，不等于成果；功法、灵气环境、身体状态、悟性、指导、反馈与干扰共同决定结果。
2. **不以单一数字代替角色能力。** 境界、灵力储备、控制精度、实战经验、神识、身体素质、功法适配分别记录。
3. **进度必须有证据。** 重要成长记录“练了什么、条件如何、观察到什么、能否重复、还差什么”。
4. **开局后数值不追随剧情任意漂移。** 新证据可以修正判断，但须说明原因并同步存档。
5. **跨境能力差必须真实存在。** 低境界角色可借准备、环境、人数、情报或目标限制改变局面，但不能无代价抹平整阶差距。

## 2. 修炼进度状态

每个当前境界层次分别记录一个状态，不对玩家展示虚假的精确百分比：

- **未稳固**：刚达到当前层次，气息/灵力运行仍易波动，强行高负荷行动可能影响巩固。
- **已稳固**：基础运行稳定，可按当前能力正常行动。
- **积累中**：已完成部分必要积累，仍存在明确缺口；须写明缺口类型。
- **条件齐备**：积累与必要条件已有证据支持，可以尝试突破；不代表必然成功。
- **突破后待巩固**：已跨过门槛，但需要时间、调息或实践稳定新能力。

“积累中”可附三档文字标记：初步 / 明显 / 接近条件齐备。只有当主持端能说明依据时才可更新；不得伪装成精确的 73% 等数值。

## 3. 境界成长检查表

每次计划冲击新层次前，逐项评估：

| 维度 | 检查内容 | 不足时的常见后果 |
|---|---|---|
| 灵力积累 | 当前储备与运行稳定性是否达到功法要求 | 无法有效触及门槛，或突破中途耗竭 |
| 功法与路线 | 功法是否支持该层次；是否有缺页、冲突或错误理解 | 进展停滞、运行不稳、风险增加 |
| 身体状态 | 经脉、伤势、疲劳、饮食与睡眠是否允许 | 恢复变慢、控制下降、伤势恶化 |
| 神识与心境 | 专注、情绪、神识负荷是否适合当前方法 | 失控、判断偏差、过程被打断 |
| 环境 | 灵气、安静程度、阵法、天气与场地是否合适 | 耗时增加、效率降低、外界干扰 |
| 资源与协助 | 丹药、护法、指导、材料是否必要且适配 | 缺少必要条件，或承担额外成本 |
| 实际理解 | 是否理解关键步骤与风险信号 | 盲目重复、误把偶然现象当成突破诀窍 |

不同境界与功法对各项的要求不同；不得要求每次突破都必须服丹药、闭死关或经历心魔。

## 4. 突破风险档

风险档是主持端对已知条件的综合判断，不是独立随机骰表。

- **低风险**：积累充分、方法熟悉、身体稳定、环境合适；失败通常意味着耗时、消耗或暂时停滞，不保证零风险。
- **常规风险**：有一项明显短板，或突破条件虽基本齐备但经验不足；失败可能消耗资源、损伤状态或需要重新准备。
- **高风险**：存在多项短板、功法冲突、伤势、环境干扰，或角色明知不适仍强行尝试；应先提示角色能够察觉的风险。
- **极端风险**：以明显不完整的方法冲击关键门槛，或在危急状态下强行突破；严重后果必须由具体条件支撑，不能仅为戏剧效果而判定。

结算结果可包括：成功并稳定、成功但待巩固、取得关键理解但未突破、进展停滞、资源损耗、暂时性灵力紊乱、伤势加重。严重后果须事先存在合理风险路径；死亡不是常规失败结果。

## 5. 各境界的门槛尺度

- **感气 → 炼气**：核心是稳定感知与引导灵气，建立可重复的基础循环。不能只凭一次偶然感应判定成功。
- **炼气层次之间**：主要看灵力积累、运行稳定、当前功法支持程度及巩固情况。层数越高，所需积累与控制要求一般增加，但不按固定倍数机械增长。
- **炼气 → 筑基**：属于结构性门槛，不只是灵力数量增加；须有与路线相符的筑基方法/条件、足够准备及对失败风险的认识。不同传承可以有不同流程。
- **筑基 → 金丹**：涉及更深层的灵力凝聚与个人道路成形；所需资源、理解和风险通常明显高于低阶突破。
- **金丹 → 元婴**：涉及生命/神识/修行结构的重大变化，不能用普通闭关时长代替条件。
- **元婴 → 化神及以上**：每个大境界都必须为角色当前路线建立独立门槛、证据、资源需求与风险；不可用一条通用模板自动套完所有高境界。
- **炼虚、合体、大乘、渡劫**：只在世界与角色进程真正触及后具体化。提前设计的幕后规律可保持稳定，但不应向低境界角色强塞其无法理解的精确说明。

## 6. 资源与耗时的记录方式

每次有意义的修炼行动开始前，说明或记录：
- 目标：恢复、积累、练术、研读、调息、突破准备或正式突破；
- 预计耗时范围，而非伪精确承诺；
- 资源消耗与环境条件；
- 可观察的成功迹象与可能的干扰；
- 中断后能保留什么成果、损失什么成本。

若角色使用修炼室，费用按实际占用时长结算；若只是普通打坐，不可事后凭空追加修炼室费用。丹药按目录的效果范围处理，不能直接兑换成境界进度。

## 8. 防止成长失衡的审计问题

每次显著升级后，检查：
1. 是否有足够的过程、条件与证据？
2. 新能力是否明确边界、成本和失败风险？
3. 旧伤、债务、关系、期限是否被无故清零？
4. 装备或丹药是否被错误地当成永久属性提升？
5. 同层级角色是否仍有能力差异，且差异来自履历/路线/准备而非主持端偏爱？
6. 是否有比“突然突破”更符合因果的替代结果？

任何一项无法解释，应降低结论强度、保留不确定性，或补足真实发生的训练/资源/指导过程，而不是编造过去。
