# 《修仙》长期成长、资源压力与软锁防护规则 v0.1

> 主持端执行文件。对应用户已确认的体验方向：普通角色可以长期成长，但速度较慢；资源压力会造成阶段性卡关和迷茫感，但不得在无可行出路时把角色永久卡死。此文件不涉及、不修改隐藏剧情真相。

## 1. 设计目标

1. 普通角色的成长真实、缓慢、可追踪，不需要天命、稀有血脉或顶级宗门才能拥有未来。
2. 慢不等于停滞。每次有意义的投入至少应留下可辨识的结果：熟练度证据、错误排除、关系变化、资源积累、风险信息或下一步方向。
3. 资源不足可以迫使角色改变计划、暂缓修炼、工作、交易、求助或探索；不能靠主持端临时发钱，也不能无声关闭所有可行路线。
4. 玩家可以迷茫，角色不应被剥夺合理寻找方向的机会。主持端提供可被发现的线索，不代替玩家做决定。

## 2. 普通角色的成长曲线

### 成长的五个并行维度
- 境界：整体修为层次，最慢、门槛最高。
- 功法/术法掌握：通过重复实践、反馈和纠错逐步提高，不能因读过秘籍直接精通。
- 实战判断：通过风险管理、观察、复盘和真实压力增长。
- 技艺/社会资本：工作、交易、制作、交涉、师承、人脉等，允许在境界停滞时继续进步。
- 资源与信息：资金、材料、可靠情报、权限、可用地点和人情。

任何一次行动不必同时提高多个维度。若修为没有增长，也应如实记录行动的其他结果，不能为了安慰玩家虚报进境。

### 慢速成长的判定
- **短期（数小时至数日）**：通常获得初步理解、一次纠错、少量熟练证据或发现当前方法的问题；除非角色早已接近突破且条件充分，否则不自动升境。
- **中期（数周至数月）**：若训练稳定、方法有效、资源/环境匹配，可形成稳定技巧或明显修炼进展；仍需看角色基础、投入质量、干扰和瓶颈。
- **长期（数月以上）**：允许持续修炼、工作或研究形成复合优势，但不能把经过的日历时间直接兑换成境界。闭关的有效性取决于方法、状态、反馈与代价。
- 以上是主持端节奏锚点，不是硬性天数表；既有存档、特殊条件与明确因果优先。

## 3. 突破停滞的处理

当角色尝试多次却无明显进展时，按顺序检查：
1. **目标是否明确**：角色想解决的是灵力容量、运行稳定、功法理解、心神控制，还是境界门槛？
2. **方法是否匹配**：是否重复无效练习？是否缺乏反馈、指导、环境或恢复？
3. **状态是否妨碍**：伤势、疲劳、灵力枯竭、心神负荷、外界干扰或资源不足？
4. **是否存在真实瓶颈**：若有，至少保留一个可验证的诊断方向；不要求立即给出答案。
5. **能否换路线**：短期工作攒资源、找低成本导师、换训练方法、练基本功、调查资料、先提升其他技艺、暂时接受较慢进度。

主持端不得连续多次仅回复“没有进步”。至少说明角色能观察到的结果、当前判断的证据等级，以及一个可选的下一步调查/尝试方向。不得把未证实猜测说成确切答案。

## 4. 资源压力与经济卡关

### 压力原则
- 钱不够时，角色需要做选择；不是所有开销都可被免除。
- 维持生存的低成本路径应与昂贵修炼路径分开。角色可以暂缓高额闭关、改为基础练习、做工、接受委托、出售可合法处置的物品、借用设施或寻找同伴。
- 这些替代路径都要付出真实代价：时间、风险、声誉、承诺、机会成本或进度减慢。
- 不保证每个 NPC 都愿意帮忙，也不保证每份工作安全、稳定或报酬优厚。
- 不凭空赠送灵石、突然打折或修改已确认物价来解除困境。

### 软锁检查
在结算重大花费、永久失去关键资源或拒绝关键人物提议后，主持端内部检查：
- 角色是否仍有至少一种符合其能力与已知世界条件的可行动方案？
- 若没有，是否是玩家明确接受的高风险后果，且之前已提示可察觉风险？
- 若不是，必须找出遗漏的合法方案、可调查信息或可以协商的条件；不能强塞救援剧情。

软锁防护不等于保证角色舒适或保证成功。它只保证世界没有因主持端忘记一个合理选项而意外变成无解状态。

## 5. 迷茫与方向提示：三级线索

当玩家表示不知道接下来做什么，或角色经过一段时间仍找不到方向时，按需要提供以下层级：

- **一级：环境提示**——描述当前可观察到的需求、人物活动、公告、市场变化、训练反馈或时间限制。只给角色有理由注意到的信息。
- **二级：行动提示**——列出 2–4 个可尝试方向，例如继续练习并记录变化、询问某类人、找工作/交易、调查某条传闻、休整或离开。明确这不是全部选项。
- **三级：结构性提示**——玩家仍迷茫时，简述目前最值得解决的实际瓶颈及其证据，例如“缺的不是时间，而是能验证方法是否有效的反馈”。可指出可能的求证方式，但不替玩家决定。

提示必须避免把某个方向伪装成唯一主线；拒绝提示中的选项不应自动惩罚角色。

## 6. 经济和成长反馈账本

重要修炼或经济阶段结束后，简要列出：
- 本次投入：时间、灵石/材料、体力/心神、关系承诺。
- 可确认收获：技能证据、资源、信息、关系变化或风险降低。
- 未解决的瓶颈：明确是事实、推断还是未知。
- 下一步可行路线：至少一个低成本路线（若世界条件允许）和一个更快但代价更高的路线。

不要显示所有幕后推演，也不要为了“给玩家目标”捏造角色无法知道的真相。

## 7. 示例：低阶修士资金不足

角色想租用昂贵聚灵室，但只剩 12 碎灵。正确处理：
- 说明现有余额和已知费用，不替角色做决定。
- 可选方向包括：先做短工攒钱、使用免费但效果较弱的基础场地、向熟人询问借用条件、把修炼目标拆成低成本基本功、暂缓修炼先调查更便宜的资源。
- 每条路线按时间、风险、报酬和关系成本结算；不能保证工作一定有，也不能突然出现免费聚灵室。
- 若玩家选择什么都不做，世界时间仍可能推进，但不得凭空制造惩罚。

## 8. 验收条件

- [ ] 境界成长慢，但功法、信息、技艺、关系或资源至少有机会留下进展。
- [ ] 同一失败方法重复使用时，主持端能解释为什么没有效果。
- [ ] 资金不足不会自动触发救援或强制主线。
- [ ] 玩家迷茫时可以获得不剧透、不强迫的分层提示。
- [ ] 所有提示都不改变隐藏历史、NPC真实动机或既有因果。
- [ ] 若玩家选择高风险且接受已提示的后果，主持端不强行消除后果。
