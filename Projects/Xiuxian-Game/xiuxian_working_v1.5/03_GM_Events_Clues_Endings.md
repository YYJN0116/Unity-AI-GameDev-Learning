# 《修仙》主持端事件、线索与结局机制 v0.1

> 主持端内部文件。用于运行开放式故事，不是固定剧情流程。

## 1. 事件状态
每个事件至少处于以下一种状态：
- 潜在：条件可能满足，但尚未启动。
- 活跃：正在发展，世界中的参与者已采取行动。
- 受阻：某些条件暂时无法满足，可能恢复或转向。
- 已解决：达成某种结果，不等于所有参与者都满意。
- 已错过：关键窗口关闭，原机会不再存在。
- 被改写：玩家或其他世界行动改变了原先可能发生的结果。
- 已失效：前置条件已不可能满足；保留原因与替代后果。

## 2. 事件记录模板
ID、标题（主持端）、状态、起因、触发条件、时间窗口、参与者、各方目标、资源与能力、已知情报、潜在行动、玩家可影响点、可能结果、失败路径、间接影响、关联线索、关联档案、最后核对时间。

## 3. 事件推进原则
- 世界行动来自人物目标、利益、能力、信息、资源、时间与环境。
- 事件不会因玩家不在场而自动暂停；但离场后结果应按既定条件发展，不可随意跳到最戏剧化的结局。
- 玩家可以通过谈判、交易、调查、破坏、合作、撤退、等待或完全不同的创意行动介入。
- 未预见的合理行动先检查世界规则与因果，再判定结果；不得仅因没写进预设选项就拒绝。
- 事件可以局部解决，也可以留下后续影响；不要求每条支线连接世界级主线。

## 4. 线索公平性
每条关键线索记录：真实含义、可观察形式、出现条件、发现所需能力/时间/工具/关系、可能的替代解释、来源可靠性、是否可能被破坏或错过、相关线索与最终验证方式。

主持端必须区分：
- 角色能直接观察到的事实；
- 角色基于证据作出的推断；
- 主持端知道但角色尚未知晓的真实情况。

若角色能力与行动足以发现线索，应给予对应信息。失败应来自具体条件（距离、遮蔽、时间不足、技能不足、误导等），而不是主持端需要保守秘密。

## 5. 分支与结局
不预写一条唯一通关路径。预先设计的是结局的因果条件和世界状态变化，而不是要求玩家按顺序完成的任务清单。

结局维度可以包括：
- 角色个人目标与修行道路；
- 重要关系的维持、破裂、修复或转变；
- 势力格局与地方秩序；
- 历史秘密被揭露、误解、局部理解或未被发现；
- 重大隐患被修补、封存、利用、恶化或暂时搁置；
- 角色存活、退隐、远行、失败、传承或其他符合世界规则的归宿。

结局必须由实际行动、世界状态、资源、人物决策与因果条件共同决定。不存在自动救世结局，也不存在因玩家不追主线就判定其人生失败的规则。

## 6. 结局防作弊规则
- 不因玩家接近真相就临时提高难度或改变事实。
- 不因玩家忽略主线就强行制造事件逼其回归。
- 不因玩家提出某种结局猜测就改变既有条件。
- 未预先设定的合理结局可以自然生成，但必须遵循世界规则并记录原因。
- 重要失败与不可逆损失应在角色有能力识别时提供合理风险信号。
