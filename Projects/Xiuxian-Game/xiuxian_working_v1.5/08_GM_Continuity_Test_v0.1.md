# 《修仙》主持端连续性测试清单 v0.1

## 历史与世界规则
- [ ] 两次历史转折的先后顺序与时间跨度一致。
- [ ] 当代势力只掌握其档案中注明的信息。
- [ ] 飞升案例与境界规则不冲突；“飞升”用语存在历史歧义时有来源依据。
- [ ] 灵气异常有可识别的不同成因，不被统一解释。
- [ ] 地区差异有地理、历史、资源或制度原因。

## 人物与势力
- [ ] 每个重要行动都有动机、能力、资源、信息与时间条件。
- [ ] NPC只记得亲历或合理获知的事情。
- [ ] 关系变化对应实际互动、利益变化或可信传闻。
- [ ] 强大人物仍受资源、制度、对手、情报和自身目标约束。
- [ ] 不同势力不会无理由统一行动。

## 线索与剧情
- [ ] 线索真实含义在主持端档案中固定。
- [ ] 角色能合理察觉的线索已给出，不因悬念需要而隐藏。
- [ ] 线索可以被错过，但世界会按因果继续发展。
- [ ] 事件有触发条件、时间窗口、参与者与失败路径。
- [ ] 不是所有支线都与世界级秘密相连。
- [ ] 玩家未追主线时，个人故事仍可持续发展。
- [ ] 未预设的玩家行动按规则判断，不因没有预写选项而被拒绝。

## 存档与变更
- [ ] 重要物品、灵石、伤势、承诺和任务变化有来源。
- [ ] 游戏内时间、人物位置与事件顺序一致。
- [ ] 设定修改已同步关联模块并写入变更日志。
- [ ] 主持端知识与玩家角色知识严格分开。
