# 《修仙》基础数值基线 v0.1

> 主持端内部执行基线。用途是保持物价、时间与行动结算前后一致，不把世界变成精确模拟器。标为“暂定”的数字可在正式开局前统一校准；开局后不得为迎合单次结果而随意改动。

## 1. 记账精度与通用原则

- 时间记到刻/时辰/日；只有在战斗或限时行动中才需要细到呼吸、瞬息。
- 灵石账目必须整数记录；大宗交易可用“枚/块/批”但必须定义换算。
- 本文件的价格是普通地区的**基准报价**，不是全世界统一价格，也不代表所有店铺都有货。
- 价格偏离基准时，记录原因：供需、品质、稀缺、运输、风险、关系、季节或议价。
- 不把现实分钟直接等同游戏时间；游戏世界采用自身日历。开局前填写具体年月日。

## 2. 灵石单位与低阶生活基准（暂定）

采用低阶灵石作为常用记账单位：`1枚低阶灵石 = 10枚碎灵`。中阶、高阶灵石暂不设强制兑换比率；大额交易须双方认可折价，因为纯度、用途和流通性可能不同。

| 项目 | 普通地区参考价 | 备注 |
|---|---:|---|
| 普通凡人一餐 | 2–8枚铜钱 | 以凡人货币结算，不必强行换算灵石 |
| 普通客房一夜 | 10–40枚铜钱 | 节庆、战乱、旺季可变 |
| 修士简餐/基础补给 | 1–3碎灵或等值货币 | 依地区与食材而变 |
| 普通客房一夜（修士常住区） | 2–8碎灵 | 不含灵气辅助 |
| 简单修炼室一时辰 | 1–4枚低阶灵石 | 只有提供稳定灵气或阵法辅助的房间适用 |
| 普通低阶符箓 | 2–10碎灵 | 依用途、品质、成功率而变 |
| 常见低阶药材一份 | 1–8碎灵 | 稀缺药材不套用此区间 |
| 基础疗伤散/常见药剂 | 5–20碎灵 | 主要缓解轻伤，不保证治疗经脉损伤 |
| 普通短途驿车/渡运 | 2–20枚铜钱 | 修士专用或危险路段另计 |
| 低阶修士一日基础开销 | 5–20碎灵 | 食宿、消耗品；不含修炼室、丹药与装备 |

### 经济执行要求
- 这些价格只为开局地区建立一致起点。开局地区正式命名后，主持端需选定本地价格系数：低成本 0.7–0.9、普通 1.0、昂贵 1.2–1.6；极端短缺另行说明。
- 凡人货币与灵石市场不完全互通。普通店家可能拒收灵石，修士商铺也未必接受大量铜钱。
- 价格不是购买权保证：还需考虑存货、身份、时间、当地禁令和交易风险。
- 议价通常只能改变部分价格，除非玩家提出了真实有价值的交换条件、掌握可靠行情或有长期信用。

## 3. 行动耗时基线（暂定）

| 行动 | 基准时间 | 可能调整因素 |
|---|---|---|
| 简短交谈/查看明显物件 | 数刻以内 | 复杂谈判、隐蔽观察会更久 |
| 搜查一间普通房间 | 1–4刻 | 隐藏夹层、危险、专业工具、房间大小 |
| 认真盘问一名愿意交谈的人 | 1–3刻 | 抵触、翻译、关系、需验证说法 |
| 在市集询价并比对数家 | 2–6刻 | 市集规模、目标稀缺度、是否熟门熟路 |
| 制作简单日用品/修补普通物件 | 数刻至半日 | 工具、熟练度、材料状况 |
| 处理轻伤 | 数刻至数时辰 | 伤口位置、工具与施治者经验 |
| 城镇内步行跨区 | 1–4刻 | 城镇规模、拥挤、天气、门禁 |
| 平坦官道步行 | 每时辰约 4–6 公里 | 负重、体能、天气、路况、同行者 |
| 普通山路步行 | 每时辰约 1–3 公里 | 陡峭、植被、夜间、负重、危险 |
| 有路引的普通商队同行 | 按商队速度结算 | 停靠、装卸、盘查、天气 |

“刻”在各地可有地方习惯；开局地区必须说明本地常用的日晷/更次/时辰体系，主持端在存档中统一换算。表格中的距离只是初始估算，不覆盖明确地图与已记录路线。

## 4. 修炼时间不等于境界进度

任何修炼安排都先确定目标。若没有经过验证的具体功法参数，不承诺固定“几天升一层”。按以下可观察成果记录：

- **调息/恢复**：改善灵力控制或疲劳；效果受伤势与环境限制。
- **日常积累**：缓慢增加灵力储备或稳定性，不自动突破。
- **专项练习**：提升某一项术法、武技或技艺的熟练度，通常需要重复练习和反馈。
- **研读/参悟**：可能获得理解、发现功法缺陷或确认不适配；不是单纯挂机时长。
- **突破准备**：检查积累、状态、资源、环境与风险，准备完成不等于突破成功。

### 成长阶段的操作口径
- 未接触 → 初识：获得可靠基础解释或直接观察到现象。
- 初识 → 入门：在指导或足够反馈下，能完成基础操作。
- 入门 → 熟练：在常见条件下重复稳定使用，并能识别典型错误。
- 熟练 → 精通：能应对变化条件、优化流程或解释关键原理。
- 精通 → 自成体系：形成可验证的独立方法、改良或传授体系。

这些阶段是描述能力的标签，不是自动计时奖励。若训练质量低、缺少反馈、练习对象不合适，花费时间也可能只得到有限进展。

## 5. 伤势与恢复记账

每项伤势至少记录：部位/类型、严重程度、当前限制、治疗方式、估计恢复窗口、恶化条件、是否可能留后患。

| 状态 | 主持端必须追踪的内容 |
|---|---|
| 轻微 | 疼痛、出血、短暂动作影响；合理处理后可较快改善 |
| 行动受限 | 某些动作/速度/精细控制下降；记录具体受限行为与恢复条件 |
| 严重 | 影响战斗、修炼或日常行动；继续活动有明确风险，需要治疗与时间 |
| 危急 | 有即时生命危险或不可逆损伤风险；优先处理，不能靠普通睡眠自动恢复 |
| 灵力紊乱 | 可调用灵力、控制稳定性、施法可靠性受影响；与外伤分开记录 |
| 神识过载 | 感知、集中、判断或继续使用神识的能力受限；强行使用可能恶化 |

治疗资源只能对其作用范围内的问题有效。若治疗者无法诊断、材料不匹配或伤势原因未解除，疗效应受限并说明原因。

## 6. 交易与库存账本最小格式

每笔交易记录：`游戏日期｜地点｜物品/服务｜数量｜单价｜总价｜付款/交换物｜交易对象｜价格偏差原因｜是否欠账/有条件`。

消耗品使用记录：`物品｜使用数量｜用途｜实际效果｜剩余数量｜是否发现副作用`。

对不确定价值的物品，不凭空给出精准估价。可先给“低/中/高价值区间”，再通过鉴定、比价或实际成交逐步收窄。

## 7. 开局校准清单

开局前必须实际填写：
1. 当地铜钱与碎灵/低阶灵石的流通关系；
2. 一夜住宿、一日基本食物、普通短途交通的本地基准；
3. 最常用修炼服务的价格与是否有空位；
4. 最近三个地点的正常路程与恶劣天气路程；
5. 游戏日历与一天分段；
6. 开局角色已有资源与已知物价来源。

若尚未填写，不要在游戏中临时声称角色“早该知道”精确价格。可以通过询价获得行情，并把首次确认结果写入地区资料。
