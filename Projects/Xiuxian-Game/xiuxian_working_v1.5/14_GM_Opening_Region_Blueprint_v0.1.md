# 《修仙》开局地区构建蓝图 v0.1

> 主持端准备档案。这里定义开局地区的功能与边界，不强制玩家必须从此地开始，也不预先锁死玩家身份、灵根、出身或开局境界。

## 1. 地区设计目标

开局地区应能支持至少五种不同玩法：基础修炼、谋生/交易、地方人际、野外探索、进入或拒绝势力。它应有可理解的日常生活与实际资源限制，不应一开始就把所有大势力和世界级秘密堆在玩家面前。

## 2. 建议的地区骨架（暂定，可在开局时具体化）

**地区类型：中等规模的山河交通节点**。一座有常住凡人居民、低阶修士、行商、短期旅人和周边村镇的城镇，附近有山林、水系、旧驿道及一处需要定期维护的公共灵气设施。它不是天下中心，也不是与世隔绝的新手村。

### 五个可用地点槽位
1. **市集/交易街**：日常物资、低阶材料、消息与价格谈判；不同摊贩可信度不同。
2. **修士聚集处**：租用修炼室、发布委托、交换功法常识、接触地方组织；服务要收费且可能有门槛。
3. **凡人生活区**：住宿、饮食、手艺、家族与生计；可观察修士行动对普通人的影响。
4. **城外交通线**：驿道、渡口、山路、护送与失踪事件；路程和天气真实影响行动。
5. **近郊异常/旧设施**：有明确可见征兆与局部风险，但不必然连接世界级历史。

## 3. 势力密度上限

开局地区最多安排：
- 1 个具有正式规章、能提供修炼/任务入口的本地组织；
- 1 个掌握交易或交通资源的商业组织；
- 1 个不完全服从上述组织的地方传承、家族或独立人物；
- 其余势力只通过有限驻点、商旅、传闻或外部影响出现。

此为防止开局信息过载的默认建议，不是世界硬限制。玩家主动寻找更大的势力时，按交通、介绍、身份、费用与时间安排接触。

## 4. 开局前必须实际填定的参数

| 参数 | 开局时必须有答案 | 设定原则 |
|---|---|---|
| 地名与地理 | 城镇、附近地貌、所属国家/区域 | 名称可新建，但需记录，之后不可随意改名 |
| 日历 | 当前年月/季节、当地计时习惯 | 统一存档，不用现实日期替代游戏日期 |
| 路程 | 到最近村镇、山林、主要交通节点的时间 | 依据交通方式、天气、修为与负重调整 |
| 经济 | 普通饮食、住宿、交通、基础修炼服务的大致价位 | 先定基准，再解释议价与地区差异 |
| 公共规矩 | 武力冲突、携带法器、夜间出入、委托纠纷的处理方式 | 规则须可被角色提前获知或观察 |
| 修炼资源 | 本地灵气水平、可租用场地、常见材料 | 不让新手地区无成本提供稀有资源 |
| 事件 | 至少 2 个可选的地方事件，1 个日常机会 | 事件可拒绝，不得把全部事件绑定主线 |

## 5. 开局引入方式

开局先呈现一个可行动的当下场景，给出角色能够直接感知的细节、眼前目标与现实限制。不要先用长篇百科讲完世界历史。让玩家能立即选择行动；若背景缺口会影响行动可行性，再补充必要信息。

可用的开局压力类型（择一或组合）：
- 有期限但并非生死攸关的委托；
- 一笔需要权衡的支出或短期谋生机会；
- 一个可观察但解释不明的地方现象；
- 一段需要处理的人际承诺；
- 一项修炼上的具体瓶颈。

不得强迫角色接受任务。拒绝后仍要有可玩的日常路径；世界后续变化按因果推进。

## 6. 开局公平性检查

- 角色的出生、境界、灵根、技艺与初始物资必须经玩家确认或明确授权随机生成。
- 若角色有背景优势，须落实到资源、人脉、知识或训练，不可只给空泛称号。
- 若角色有负担，需说明其可见影响、触发条件与处理方式。
- 任何关键选择不得以玩家尚未获得的信息作为唯一正确答案。
- 第一场冲突不以强敌碾压来“证明世界危险”；先让玩家理解规则和自身能力。
