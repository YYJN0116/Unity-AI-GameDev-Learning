# 《修仙》跨档案因果与连续性校验 v0.1

## 已检查的冲突风险

- **世界级真相是否被单一人物垄断？** 否。历史转折来自多方行为、制度依赖与信息不对称；“无名旧系”明确不是统一组织。
- **是否把所有地方异常连成主线？** 否。EV-01、EV-02、EV-03、EV-04、EV-06、EV-08 均可独立发生；联动需要证据。
- **是否强迫玩家救世？** 否。玩家可以专注个人修行、关系、地方事务、交易或远行；世界级结局不是默认目标。
- **是否允许世界在玩家缺席时发展？** 是。事件按参与者能力、资源、动机、时间与环境推进；不得直接跳到最戏剧化结果。
- **线索是否公平？** 每个事件至少有可观察形式、替代解释和后续验证方向；若角色有合理能力与行动，应给出对应发现。
- **人物是否全知？** 六类人物均写明知道/不知道的边界；任何跨区信息需要合理传播渠道与时间。
- **是否存在为保留剧情而强行恶化的情况？** 明确禁止。EV-07 可以真的回稳；事件也可以解决、错过、转向或与主线无关。
- **玩家的高境界是否自动压倒一切？** 否。事件解决方式仍取决于信息、关系、资源、地形、规则、代价与对手的合理应对。

## 开局前仍需明确的执行参数

1. 当前开局地点、当地日历与常见路程时间。
2. 玩家角色境界、灵根/体质、已掌握技艺、起始资源与已知人脉。
3. 当前地区有哪些势力真实存在；不可把所有幕后势力自动塞进开局。
4. 对当前活动事件设定时间窗口时，必须写明窗口依据、可见风险与错过后的现实后果。
5. 每次存档需同步：时间、地点、角色状态、资源变化、关系变化、已知事实/传闻/线索、活跃事件与变更记录。

## 下一轮校验重点

- 修炼资源、突破风险、伤势恢复与日历时间之间的数值/叙事一致性。
- 交易价格和资源稀缺性是否随地区、季节、风险与运输成本变化，而非随剧情随意变化。
- 玩家手册只保留角色可合理知道的规则；主持端真相不得混入公开版。
