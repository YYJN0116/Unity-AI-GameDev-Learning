# 《修仙》事件因果网与动态事件种子 v0.2

> 主持端机密。事件是可被世界条件激活的模拟素材，不是强制任务链。未满足触发条件时不得硬推；玩家不介入时，事件仍按参与者能力与现实限制发展。

## 一、全局因果骨架（不等于唯一剧情线）

- **历史底层**：古代大型灵气循环工程改变了部分区域的灵脉分配与跨域通行条件，并形成长期依赖。工程本身有多方参与、不同动机与不同阶段，不归属于单一幕后人物。
- **当代表层**：部分旧工程的维护、封存、重启与改造正在发生；地方灵脉异常、商路成本变化、遗址争议、研究者的文献分歧可能互相关联，也可能只是局部事件。
- **传播限制**：每个地区只会观察到本地现象。线索跨区传播需时间、可信信使、交易记录或可验证材料；不同势力可能对同一证据提出不同解释。
- **核心变量**：旧工程状态、当地灵脉承载、维护者知识、地方利益冲突、信息传播程度、玩家介入方式。禁止把任何单一变量当成万能开关。

## 二、动态事件种子

### EV-01｜旧路灵息失衡
- **类别/初始状态**：地方交通与资源事件；潜在。
- **触发条件**：一条旧商路的灵气环境持续偏离季节常态，且至少一支运输队因此损失时间、货物或护卫。
- **窗口**：数日到数周；越晚调查，现场痕迹越容易被天气、过路人和后续事故覆盖。
- **参与者目标**：百川行会当地分会想判断是否改道；地方修士想确认是否影响修炼；沿路居民希望交通与生计不被切断。
- **可见线索**：运输成本变化、牲畜避开某段路、不同年份的驿站记录、灵石消耗异常。每条单独看都不足以证明古代工程相关。
- **介入点**：跟队观察、比对旧账、询问居民、测量灵气、绕路、修补局部阵法、向商会交易情报。
- **不介入结果**：商路可能改道，居民收入下降；异常未必升级。若当地条件稳定，现象也可能自行减弱。
- **分支**：证实为季节性变化；发现人为维护失误；发现与旧设施有关的局部证据；被商会夸大成涨价理由。
- **防误判**：此事件默认不是世界危机，不保证含有主线线索。

### EV-02｜失踪的阵务维护者
- **类别/初始状态**：地方调查；条件潜在。
- **触发条件**：某处阵法的定期维护缺席，且替补人员无法按既有记录安全完成维护。
- **参与者目标**：守护传承希望找回维护者并避免外界接管；家属关心安危；外来研究者希望获取阵法结构资料。
- **时间窗口**：取决于阵法周期；主持端须先明确失效征兆与剩余安全时间，不能事后临时设置倒计时。
- **线索**：维护日志存在重复抄写痕迹；工具被带走但部分生活物品仍在；最后一次出行目的与公开说法不完全相符。
- **介入点**：搜寻、谈判、核对日志、协助临时维护、调查家属与同门关系。
- **不介入结果**：阵法按已知缺陷逐步衰弱或被替补方案暂时稳定；维护者的个人命运按其行动和处境决定，不自动死亡。
- **分支**：主动离开以反对封锁；被困在危险区域；卷入传承内部冲突；发现维护记录存在长期误差。
- **独立性**：维护者可能只是因个人债务、疾病、家庭矛盾或研究执念失踪，不必与古史主线有关。

### EV-03｜书院残卷争议
- **类别/初始状态**：学术、声誉与知识产权；潜在。
- **触发条件**：两份声称来自同一年代的文本出现无法用普通抄写差错解释的差异。
- **参与者目标**：实证派要求查原件；正统派担心学术与传承声望受损；实验派希望测试其中的术理；捐资者希望控制公开节奏。
- **窗口**：数周至数月；争议先在小圈子传播，公开后更难回收错误说法。
- **线索**：纸墨年代、术语演变、地名沿革、缺页装订痕迹、引用链。每项检测都有成本与误差范围。
- **介入点**：校勘、寻找来源、保护证人、公开证据、私下交易、指出研究方法问题。
- **不介入结果**：书院可能形成暂定结论，也可能压下争议；不同学派继续持不同意见。
- **分支**：文本为后世拼合；原文正确但被错误注释；两个版本分别记录不同地区事件；有人故意伪造，但动机可能是名誉、钱财或地方政治，而非世界级阴谋。

### EV-04｜封存与开放之争
- **类别/初始状态**：地方权力冲突；潜在。
- **触发条件**：某古迹周边居民或修士提出开放通行、采集或研究的要求，守护者认为现有规矩不可持续。
- **参与者目标**：封守派降低事故风险；开放派防止知识失传；居民需要土地、药材或道路；外来势力寻求研究权限。
- **窗口**：由地方收成、维护周期与谈判期限共同决定，不预设统一天数。
- **线索**：过去事故记录、旧规矩的适用条件、不同区域边界的维护差异、谁实际承担封锁成本。
- **介入点**：调停、提出有限开放制度、协助风险评估、寻找替代资源、公开隐瞒的事故记录。
- **不介入结果**：冲突可能由地方首领裁定、持续僵持、出现非法进入，或通过资源补偿降温。
- **分支**：合作维护；强制封锁；遗址开放但设限；守护传承分裂；地方形成新的管理约定。
- **约束**：不存在必然正确的一方；安全、知识、民生与自主权均须具体衡量。

### EV-05｜跨域协作令
- **类别/初始状态**：势力政治；潜在。
- **触发条件**：至少两个地区出现可核实、但不一定同源的异常，地方机构无力独立判断或处理。
- **参与者目标**：玄衡道盟协调资源并维护规则权威；成员势力希望获得援助但不愿交出本地决策权；商会希望通行稳定。
- **窗口**：从发出求援到使者抵达存在真实路程时间；消息可能延误、失真或被拦截。
- **线索**：会议摘要、援助清单、被删去的异议、成员对风险的不同评估。
- **介入点**：作为信使、顾问、地方代表或独立调查者参与；也可拒绝卷入。
- **不介入结果**：协作可能迟缓、缩小范围、由其他势力填补空缺，或因证据不足而不行动。
- **分支**：形成临时合作；合作破裂；地方独立解决；一方借援助扩大影响力。
- **防全知**：道盟不能仅凭两地异常就准确知道古代机制，也不能自动调动所有宗门。

### EV-06｜被高价收购的旧材料
- **类别/初始状态**：交易、情报与道德抉择；潜在。
- **触发条件**：某件来源不明的旧物或残页进入市场，买方开出明显高于材料表面价值的价格。
- **参与者目标**：卖方希望获利或脱手风险；买方可能是研究者、收藏者、地方势力或投机商；中间人保护客户身份。
- **窗口**：交易可能在数小时到数日内完成，受竞价、运输与鉴定影响。
- **线索**：价格与物品实用价值不匹配；卖方隐瞒取得方式；旧物有维修痕迹但不具备直接证明力。
- **介入点**：鉴定、追查来源、参与竞价、劝说卖方、设置交换条件、放弃交易。
- **不介入结果**：物品转手，后续去向取决于买方资源和动机；不自动引发追杀。
- **分支**：普通收藏炒作；买方需要某个局部技术部件；物品能证明一段地方历史；买方误以为它有更大价值。

### EV-07｜灵脉短期回稳
- **类别/初始状态**：异常缓解与误判；潜在。
- **触发条件**：一处持续异常的灵脉指标短期恢复正常，但维护记录与环境条件没有明确解释。
- **参与者目标**：当地修士想恢复修炼与生产；维护者想确认是否可撤除临时措施；投机者可能借回稳宣称问题已彻底解决。
- **窗口**：需连续观察多个周期，不能凭单次读数判定永久稳定。
- **线索**：不同测点恢复程度不同；旧记录显示曾有相似短期波动；局部设施仍有未解决的损耗。
- **介入点**：延长观察、比对不同测点、公开不确定性、修复设施、撤离或继续投入资源。
- **不介入结果**：部分人恢复正常生活，部分人承担后续风险；也可能确实长期回稳。
- **分支**：临时自然波动；维护措施有效但不彻底；异常转移至另一处；原先的异常判断本身有误。
- **关键规则**：不能为了保留剧情而强行让它再次恶化。

### EV-08｜证人公开改口
- **类别/初始状态**：证据可信度与人际关系；潜在。
- **触发条件**：某证人的说法与新证据冲突，或其此前隐瞒的利益关系被发现。
- **参与者目标**：证人保护自身安全、亲友或名誉；调查者希望厘清事实；相关势力希望控制影响范围。
- **窗口**：由公开场合、证据出现时间和证人的风险感知决定。
- **线索**：证词中可核验的细节、前后矛盾、证人实际能观察到的范围、第三方记录。
- **介入点**：私下沟通、交叉核验、提供保护、公开质疑、允许证人保留不确定部分。
- **不介入结果**：证词可能被当作不可靠而搁置，也可能在后来获得旁证；不自动导致全案崩溃。
- **分支**：故意撒谎；诚实但记忆错误；只说了自己看到的一部分；受到压力后改变说法；新证据确实推翻了旧判断。

## 三、事件联动矩阵

| 起始事件 | 可能联动 | 联动成立所需证据/条件 | 不可默认的关联 |
|---|---|---|---|
| EV-01 旧路失衡 | EV-05 跨域协作令 | 多地独立数据可比较，且影响超出单一商路 | 不可因灵气异常就直接判定古代工程故障 |
| EV-02 维护者失踪 | EV-04 封存与开放之争 | 失踪确实影响维护能力，且相关人员公开争执 | 不可把失踪者预设为叛徒或被绑架 |
| EV-03 残卷争议 | EV-06 旧材料交易 | 市场物品与文本存在可验证来源联系 | 不可把所有古籍争议都设为伪造阴谋 |
| EV-04 封存与开放之争 | EV-05 跨域协作令 | 地方争议造成跨域安全或规则冲突 | 不可让道盟自动拥有最终裁决权 |
| EV-06 旧材料交易 | EV-03 残卷争议 | 鉴定显示材料确实能补充或反驳某文本 | 不可只因价格高就断定其重要性 |
| EV-07 灵脉回稳 | EV-01 旧路失衡 | 同一地区、时间与测点数据存在合理联系 | 不可为延续主线而否定真实回稳 |
| EV-08 证人改口 | 任一调查事件 | 证人实际接触过相关事实，且证词有可检验部分 | 不可让证人无缘无故知道幕后真相 |

## 四、运行时记录要求

每次让事件推进前，写下：
1. 参与者此刻相信什么（可以错）；
2. 参与者能做什么（能力、资源、关系）；
3. 参与者为何现在行动或不行动；
4. 时间经过后哪些客观条件改变；
5. 玩家若完全不在场，最合理的结果是什么；
6. 结果会留下什么可追踪证据。

每次玩家介入后，只更新受到因果影响的事件；不得因为一个事件推进，就让所有其他事件同步升级。对于随机事件，先确定可能范围与权重，再按当前环境选择；不得在结果发生后倒编原因。
